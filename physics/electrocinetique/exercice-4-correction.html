a) Current divider — putting currents in quadrature

Setting up the equations for the two branches

The two branches are in parallel, driven by the same voltage $\underline{U}$ (complex notation). Branch 1: the coil alone, modeled as a series $RL$ circuit. Branch 2: the same coil in series with the capacitor $C$.

$$\underline{Z_1} = R + j\omega L,\qquad \underline{Z_2} = R + j\omega L + \frac{1}{j\omega C}.$$

Recall that $\dfrac{1}{j} = -j$ because $j \cdot j = -1$. Therefore:

$$\frac{1}{j\omega C} = -\frac{j}{\omega C},\qquad \underline{Z_2} = R + j\!\left(\omega L - \frac{1}{\omega C}\right).$$

1. Lead or lag? Form of the ratio

Since both branches see the same voltage $\underline{U}$, we have $\underline{I_1} = \underline{U}/\underline{Z_1}$ and $\underline{I_2} = \underline{U}/\underline{Z_2}$, so:

$$\frac{\underline{I_1}}{\underline{I_2}} = \frac{\underline{U}/\underline{Z_1}}{\underline{U}/\underline{Z_2}} = \frac{\underline{Z_2}}{\underline{Z_1}}.$$

The series capacitor introduces a negative capacitive term $-\dfrac{1}{\omega C}$ that adds to the inductive reactance $\omega L$. Branch 2 is therefore "less inductive" (or even capacitive) than branch 1. Consequently, $i_2$ leads $i_1$ — that is exactly what the expression $\dfrac{\underline{I_1}}{\underline{I_2}} = -jk$ with $k > 0$ conveys: multiplying by $-j$ amounts to a $90^\circ$ lag, so $\underline{I_1}$ lags $\underline{I_2}$ by $90^\circ$.

2. Determining C with the current divider

We want the ratio $\dfrac{\underline{Z_2}}{\underline{Z_1}}$ to be a negative pure imaginary. We multiply numerator and denominator by the conjugate of $\underline{Z_1}$:

$$\frac{\underline{Z_2}}{\underline{Z_1}} = \frac{\underline{Z_2}\,\overline{\underline{Z_1}}}{|\underline{Z_1}|^2} = \frac{\bigl[R + j(\omega L - 1/\omega C)\bigr]\,(R - j\omega L)}{R^2 + (\omega L)^2}.$$

Let us expand the numerator (writing $X_2 = \omega L - 1/(\omega C)$ to lighten the notation):

$$(R + jX_2)(R - j\omega L) = R^2 + X_2\,\omega L + j\bigl(R X_2 - R\,\omega L\bigr).$$

For the ratio to be pure imaginary, the real part must vanish:

$$R^2 + X_2\,\omega L = 0 \;\Longleftrightarrow\; X_2 = -\frac{R^2}{\omega L} \;\Longleftrightarrow\; \omega L - \frac{1}{\omega C} = -\frac{R^2}{\omega L}.$$

We isolate $\dfrac{1}{\omega C}$:

$$\frac{1}{\omega C} = \omega L + \frac{R^2}{\omega L} = \frac{(\omega L)^2 + R^2}{\omega L}.$$

Hence finally:

$$\boxed{\,C = \frac{L}{R^2 + (\omega L)^2}\,}$$

3. Value of the factor k

With this value of $C$, the real part is zero. The imaginary coefficient remains:

$$\frac{\underline{I_1}}{\underline{I_2}} = j\,\frac{R(X_2 - \omega L)}{R^2 + (\omega L)^2}.$$

Since $X_2 = -R^2/(\omega L)$, we compute $X_2 - \omega L = -R^2/(\omega L) - \omega L = -\bigl[R^2 + (\omega L)^2\bigr]/(\omega L)$. Therefore:

$$\frac{\underline{I_1}}{\underline{I_2}} = j\cdot\frac{R\cdot\bigl(-[R^2+(\omega L)^2]/(\omega L)\bigr)}{R^2+(\omega L)^2} = -j\,\frac{R}{\omega L}.$$

We therefore read off:

$$\boxed{\,k = \frac{R}{\omega L}\,}$$

b) Voltage divider

Equivalent circuit

The voltage source $\underline{U}$ drives, in series, the line impedance $\underline{Z}_\text{line} = R + jX_L = 1 + j\,0.5\ \Omega$ and then the load $\underline{Z_2} = 25\,e^{j\pi/3}\ \Omega$. The voltage we seek, $\underline{U_2}$, is across $\underline{Z_2}$.

1. RMS value U₂ via the voltage divider

$$\underline{U_2} = \underline{U}\cdot\frac{\underline{Z_2}}{\underline{Z}_\text{line} + \underline{Z_2}}.$$

We express $\underline{Z_2}$ in Cartesian form to do the sum:

$$\underline{Z_2} = 25\bigl(\cos(60^\circ) + j\sin(60^\circ)\bigr) = 25\,(0.5 + j\,0.8660) = 12.5 + j\,21.65\ \Omega.$$

Hence:

$$\underline{Z}_\text{line} + \underline{Z_2} = (1 + 12.5) + j(0.5 + 21.65) = 13.5 + j\,22.15\ \Omega.$$

Magnitudes:

$$|\underline{Z_2}| = 25\ \Omega,\qquad |\underline{Z}_\text{line} + \underline{Z_2}| = \sqrt{13.5^2 + 22.15^2} = \sqrt{182.25 + 490.62} = \sqrt{672.87} \approx 25.94\ \Omega.$$

The RMS value we seek is the ratio of the magnitudes multiplied by $U$:

$$U_2 = U\cdot\frac{|\underline{Z_2}|}{|\underline{Z}_\text{line}+\underline{Z_2}|} = 240\cdot\frac{25}{25.94}\approx 231.3\ \text{V}.$$

2. Phase shift of u relative to u₂

The phase shift of $\underline{U}$ relative to $\underline{U_2}$ is the argument of $\underline{U}/\underline{U_2}$. From the divider:

$$\frac{\underline{U}}{\underline{U_2}} = \frac{\underline{Z}_\text{line}+\underline{Z_2}}{\underline{Z_2}}.$$

The argument is therefore:

$$\varphi_{u/u_2} = \arg(\underline{Z}_\text{line}+\underline{Z_2}) - \arg(\underline{Z_2}).$$

We compute each one:

$$\arg(\underline{Z}_\text{line}+\underline{Z_2}) = \arctan\!\frac{22.15}{13.5} \approx 58.65^\circ,\qquad \arg(\underline{Z_2}) = \frac{\pi}{3} = 60^\circ.$$

Therefore:

$$\boxed{\,\varphi_{u/u_2} \approx 58.65^\circ - 60^\circ \approx -1.35^\circ\,}$$

The supply voltage $u$ lags very slightly behind the voltage $u_2$ across the load. The phase shift is small, which is consistent with a line whose impedance is very small compared with that of the load.
