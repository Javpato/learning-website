Exercise 2 — Swap by pointers (C)

Problem statement

In C, references do not exist. For a function to modify a variable of its caller, it must be passed the variable's address.

/** Swaps the contents pointed to by two integer pointers.
 * @param[in/out] x, y two pointers to integers (non NULL).
 **/
void echange(int *x, int *y) {
  int t;
  t = *x;
  *x = *y;
  *y = t;
}
/* call */
echange(&a, &b);
  1. Follow the dereferences at each step.
  2. Compare with exercise 1: what exactly does the syntax change?
