Exo 2 — Échange par pointeurs (C)

Énoncé

En C, les références n'existent pas. Pour qu'une fonction modifie une variable de l'appelant, on doit lui passer son adresse.

void echange(int *x, int *y) {
  int t;
  t = *x;
  *x = *y;
  *y = t;
}
/* appel */
echange(&a, &b);
