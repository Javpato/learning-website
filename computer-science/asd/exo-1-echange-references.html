Exercise 1 — Swap by reference

Problem statement

We write the following function in C++:

/** Swaps the contents of two variables
 * @param[in/out] a, b two integer variables.
 **/
void echange(int &a, int &b) {
  int t = a;
  a = b;
  b = t;
}

We call echange(x, y) from main, with x = 3, y = 7. (The function name is echange, French for "swap", without an accent: C++ does not allow accented characters in identifiers.)

  1. Describe the state of the stack at each step.
  2. Why is passing by reference essential here?
