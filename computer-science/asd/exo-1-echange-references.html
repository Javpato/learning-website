Exo 1 — Échange par référence

Énoncé

On écrit en C++ la fonction :

void échange(int &a, int &b) {
  int t = a;
  a = b;
  b = t;
}

On appelle échange(x, y) depuis main, avec x = 3, y = 7.

  1. Décrire l'état de la pile à chaque étape.
  2. Pourquoi le passage par référence est-il indispensable ici ?
