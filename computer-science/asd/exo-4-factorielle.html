Exercise 4 — Recursive factorial

Problem statement

/** Computes n! recursively.
 * @param[in] n a non-negative integer.
 * @return n! (the product 1 × 2 × ... × n).
 **/
int factorielle(int n) {
  if (n <= 1) return 1;
  return n * factorielle(n - 1);
}
int r = factorielle(4);
  1. Trace the execution, showing the state of the stack at each call.
  2. Identify the base case. Why is it essential?
  3. Compute the final value.
