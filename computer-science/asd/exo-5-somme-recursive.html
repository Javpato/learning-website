Exo 5 — Somme récursive d'un tableau

Énoncé

int somme(int t[], int n) {
  if (n == 0) return 0;
  return t[n - 1] + somme(t, n - 1);
}
int T[4] = {5, 2, 7, 3};
int s = somme(T, 4);

  2. Quel est le cas de base ?
