Written correction — Exercise 2

The full text, to read at your own pace. For the step-by-step version with figures, see the animated correction.

1. Linearity of D

Differentiation respects sums and scalar multiples: for $p, q \in \mathbb{R}_n[X]$ and $a, b \in \mathbb{R}$,

$$\boxed{D(ap + bq) = (ap + bq)' = a\,p' + b\,q' = a\,D(p) + b\,D(q)}$$

Moreover, differentiating lowers the degree: if $\deg p \le n$ then $\deg p' \le n - 1 \le n$, so $D$ does map $\mathbb{R}_n[X]$ into itself. It is an endomorphism of a space of dimension $n + 1$.

2. Matrix of D in the canonical basis

Column $k$ of the matrix contains the coordinates of the image of the $k$-th basis vector. Now

$$D(1) = 0, \qquad D(X^k) = k\,X^{k-1} \quad (k \ge 1).$$

Each monomial moves down one step, multiplied by its exponent. For $n = 3$, in the basis $(1, X, X^2, X^3)$:

$$\operatorname{Mat}(D) = \begin{pmatrix} 0 & 1 & 0 & 0 \\ 0 & 0 & 2 & 0 \\ 0 & 0 & 0 & 3 \\ 0 & 0 & 0 & 0 \end{pmatrix}.$$

The entries $1, 2, \dots, n$ sit on the superdiagonal; everything else is zero. The matrix is strictly upper triangular: its diagonal is entirely zero.

3. Nilpotency of order exactly n + 1

Each application of $D$ drops the degree by at least 1:

$$\mathbb{R}_n[X] \xrightarrow{\;D\;} \mathbb{R}_{n-1}[X] \xrightarrow{\;D\;} \cdots \xrightarrow{\;D\;} \mathbb{R}_0[X] \xrightarrow{\;D\;} \{0\}.$$

After $n+1$ applications, every polynomial of degree $\le n$ is annihilated:

$$\boxed{D^{n+1} = 0}$$

The order is exactly $n + 1$ because $D^n \neq 0$. Indeed, differentiating the leading monomial $k$ times:

$$D^k(X^n) = n(n-1)\cdots(n-k+1)\,X^{n-k}, \qquad \text{so} \qquad D^n(X^n) = n! \neq 0.$$

$D$ is nilpotent of order $n + 1$ — which is indeed $\le \dim \mathbb{R}_n[X] = n+1$, in accordance with the general bound on the index of nilpotency.

4. Eigenvalues of D

The matrix of $D$ is triangular: its eigenvalues can be read off the diagonal, which is entirely zero. So

$$\boxed{\operatorname{Sp}(D) = \{0\}}$$

(One can also see it directly: if $D(p) = \lambda p$ with $p \neq 0$ and $\lambda \neq 0$, then $\deg p' = \deg p$, which is impossible since differentiating strictly lowers the degree. And $0$ is indeed an eigenvalue: constants satisfy $D(c) = 0$.)

5. D is not diagonalizable

We argue by contradiction: suppose $D$ is diagonalizable. Since its only eigenvalue is $0$, there would exist a basis in which its matrix is $\operatorname{diag}(0, \dots, 0)$, that is, the zero matrix. We would then have

$$D = P \cdot 0 \cdot P^{-1} = 0.$$

But $D$ is not the zero map as soon as $n \ge 1$: for instance

$$D(X) = 1 \neq 0.$$

Contradiction. So

$$\boxed{D \text{ is not diagonalizable (for } n \ge 1\text{)}}$$

This is the perfect illustration of the general principle seen on the nilpotency page: a nonzero nilpotent map is never diagonalizable.
