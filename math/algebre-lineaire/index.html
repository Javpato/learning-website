Linear algebra

Four notions that sound alike but play very different mathematical roles. Each page follows the same path: intuition, formal definition, worked example, interactive visualization, classic pitfalls, mini-exercises.

0

Nilpotency

Nilpotent = applying it again and again eventually sends everything to 0. The flagship example: differentiation on ℝₙ[X].
λ

Diagonalizability

Diagonalizable = there is a basis in which the transformation acts separately on each axis. With the shear counterexample.
tr

Trace & determinant

Trace = sum of the eigenvalues; determinant = their product. Application: transposition seen as an operator on Mₙ(ℝ).
rg

Rank

Same rank = same image dimension, not necessarily the same image. Rank as the "compression level" of a map.
