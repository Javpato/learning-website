# Plan de travail — 12 semaines (maths + physique)

Ce plan est **purement indicatif** — rien n'y est obligatoire, aucune case à
cocher, aucun ordre imposé. Tout le contenu du site reste ouvert en
permanence : tu peux explorer dans n'importe quel ordre, sauter une semaine,
en étaler une sur deux, ou piocher uniquement ce qui t'intéresse. Ce
calendrier existe seulement pour celles et ceux qui aiment avoir un fil
conducteur : il synchronise le module de mathématiques avec le parcours de
physique (électromagnétisme), de sorte que chaque outil mathématique arrive
juste avant que la physique en ait besoin.

## Comment utiliser ce plan

Une méthode qui fonctionne bien, pour chaque leçon — à adapter librement :

1. **Diagnostic** — tente les questions de démarrage sans notes, juste pour
   savoir d'où tu pars (aucun enjeu, personne ne regarde) ;
2. **Théorie** — étudie la partie compacte de la leçon ;
3. **Reconstruction** — essaie de refaire la démonstration principale de
   mémoire : c'est l'étape qui ancre vraiment ;
4. **Exercice cœur** — un exercice « cœur de gamme » du TD associé ;
5. **Transfert** — un problème en contexte chimique, pour donner du sens ;
6. **Retour à 48 h** — reviens deux jours plus tard sur un problème mélangé :
   la mémoire adore qu'on la sollicite juste avant d'oublier ;
7. **TD difficile** — garde les exercices étoilés pour quand les mécanismes
   de base sont devenus automatiques. Pas avant — et sans culpabilité.

Un rythme hebdomadaire réaliste (à moduler selon ta semaine) :

- **Mathématiques** : deux blocs de 90 minutes + un bloc de TD de 2 heures ;
- **Physique** : un bloc de théorie de 90 minutes + un bloc de problèmes de
  2 heures ;
- **Révision cumulative** : 30 à 45 minutes le week-end, en piochant dans le
  [formulaire](../formulaire) et les anciennes semaines.

Et si une semaine déborde : reprendre là où tu t'es arrêté·e est exactement
la bonne stratégie. Le plan est un guide, jamais un juge.
