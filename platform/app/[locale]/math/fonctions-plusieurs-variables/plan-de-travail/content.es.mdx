# Plan de trabajo — 12 semanas (matemáticas + física)

Este plan es **puramente orientativo**: nada es obligatorio, no hay casillas que
marcar ni se impone ningún orden. Todo el contenido del sitio permanece abierto en
todo momento: puedes explorar en cualquier orden, saltarte una semana,
repartir una entre dos semanas o escoger solo lo que te interese. Este
calendario existe únicamente para quienes prefieren tener un hilo conductor: sincroniza el
módulo de matemáticas con el itinerario de física (electromagnetismo), de modo que cada
herramienta matemática aparezca justo antes de que la física la necesite.

## Cómo usar este plan

Un método que funciona bien para cada lección — adáptalo con libertad:

1. **Diagnóstico** — intenta responder las preguntas iniciales sin apuntes, solo para
   saber desde dónde partes (no hay nada en juego y nadie te observa);
2. **Teoría** — estudia la parte compacta de la lección;
3. **Reconstrucción** — intenta rehacer de memoria la demostración principal:
   este es el paso que realmente la afianza;
4. **Ejercicio central** — un ejercicio central del TD (hoja de problemas) asociado;
5. **Transferencia** — un problema en contexto químico, para darle sentido;
6. **Regreso a las 48 h** — vuelve dos días después a un problema mixto:
   a la memoria le encanta que la pongas a prueba justo antes de olvidar;
7. **TD difícil** — reserva los ejercicios con estrella para cuando los mecanismos
   básicos se hayan vuelto automáticos. No antes, y sin culpa.

Un ritmo semanal realista (ajústalo según tu semana):

- **Matemáticas**: dos bloques de 90 minutos + un bloque de TD de 2 horas;
- **Física**: un bloque de teoría de 90 minutos + un bloque de problemas de
  2 horas;
- **Repaso acumulativo**: de 30 a 45 minutos el fin de semana, escogiendo del
  [formulario](../formulaire) y de las semanas anteriores.

Y si una semana se alarga: retomar donde lo dejaste es exactamente
la estrategia adecuada. El plan es una guía, nunca un juez.
