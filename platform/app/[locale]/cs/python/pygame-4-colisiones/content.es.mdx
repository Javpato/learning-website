# Colisiones (Pygame)

<Accroche>« ¿Chocó el jugador con la plataforma? Toda la magia de un plataformas vive en esa pregunta. »</Accroche>

Recoger una moneda, pisar una plataforma, recibir daño de un enemigo… todo son **colisiones**: dos
rectángulos que se solapan. Pygame te da la herramienta, pero conviene entender la matemática detrás.

## `pygame.Rect`

Un `Rect` es un rectángulo con posición y tamaño. Pygame trae `colliderect` para saber si dos se
tocan:

```python
jugador = pygame.Rect(50, 50, 32, 32)     # x, y, ancho, alto
moneda = pygame.Rect(60, 60, 16, 16)

if jugador.colliderect(moneda):
    print("¡Moneda recogida!")
```

## La matemática: solapamiento AABB

`colliderect` comprueba, por dentro, un **solapamiento de rectángulos alineados** (AABB): dos
rectángulos se tocan si se solapan **en los dos ejes a la vez**. Impleméntalo tú para entenderlo:

## Aterrizar sobre una plataforma

En un plataformas, cuando el jugador (que cae) colisiona con una plataforma, detienes su caída y lo
apoyas encima:

```python
if jugador.colliderect(plataforma) and vy > 0:   # cayendo
    jugador.bottom = plataforma.top               # apóyalo encima
    vy = 0                                         # deja de caer
```

<Pitfall>
Comprueba las colisiones **después** de mover al jugador, no antes. El orden de cada fotograma es:
mover (aplicar velocidad) → comprobar y resolver colisiones → dibujar. Si lo haces al revés, el
personaje se hunde en el suelo o "vibra".
</Pitfall>

## Mini-ejercicios

<Collapsible title="1. ¿Qué es un AABB?">

*Axis-Aligned Bounding Box*: un rectángulo cuyos lados están alineados con los ejes (no girado). Sus
colisiones son baratísimas de calcular — solo comparaciones — por eso son la base de casi todos los
juegos 2D.

</Collapsible>

que devuelve el índice de la primera con la que choca).
