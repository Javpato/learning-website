## Data model

Three pieces work together, and each one is the **right** structure for its job:

```python
# Shop catalog: a dict {name: price}. Looking up a price is instant.
tienda = {"Potion": 15, "Sword": 60, "Shield": 45, "Antidote": 10}

# Inventory: a list of purchased items (duplicates allowed: 3 potions).
inventario = ["Potion", "Potion", "Sword"]

# Gold available.
oro = 100
```

<Pitfall>
Pick the structure by what you need to do with it. The **catalog** is a `dict` because you look up by
name (`tienda["Sword"]`). The **inventory** is a `list` because it allows duplicates and order. And
for "which **distinct** items do I have?" you'll use a `set(inventario)`, which drops duplicates on
its own.
</Pitfall>

## Each structure in its place

- **Dictionary** for the catalog: `tienda[name]` gives you the price instantly.
- **List** for the inventory: keeps everything you buy, duplicates included.
- **Set** to answer "which item types do I have?": `set(inventario)`.
- **Comprehension** to count or sum without writing a long loop:

```python
# Total value of the bag, in one line:
valor = sum(tienda[obj] for obj in inventario)

# How many of each distinct item (the counting pattern):
conteo = {obj: inventario.count(obj) for obj in set(inventario)}
```

## Guided steps

```text
1. Define `tienda` (dict name->price), `inventario` (empty list) and `oro`.
2. Write one function per action:
     - mostrar_tienda(tienda, oro): loop over the dict with enumerate and show item and price.
     - comprar(tienda, inventario, oro, name): if there's enough gold, subtract the price and
       add the item to the inventory; return the new gold. Otherwise warn "Not enough gold".
     - mostrar_inventario(inventario, tienda): use a set to group and a comprehension to count
       each item and sum the total value.
     - vender(tienda, inventario, oro, name): if the item is in the inventory, remove it and
       recover half its price (precio // 2).
3. Main loop with while: show the menu, read the option and call the function.
4. Exit the loop when the user chooses "Quit".
```
