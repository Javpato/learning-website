# Tuplas e iteración

<Accroche>« Datos que no deben cambiar — como la posición (x, y) de un sprite — y formas elegantes de recorrerlos. »</Accroche>

Cerramos el módulo de estructuras de datos con las **tuplas** y con tres herramientas de iteración
que verás en casi todo código Python (y en todo juego): `enumerate`, `zip` y `sorted`.

## Tuplas

Una **tupla** es como una lista pero **inmutable**: no se puede cambiar tras crearla. Se escribe con
paréntesis:

```python
posicion = (3, 4)
print(posicion[0])    # 3
# posicion[0] = 9     # ¡TypeError! las tuplas no se modifican
```

Se usan para datos fijos que van juntos: la posición de un sprite `(x, y)`, un color `(r, g, b)`, el
tamaño de la pantalla `(ancho, alto)`.

## Desempaquetado

Puedes repartir los elementos de una tupla (o lista) en varias variables de golpe:

```python
posicion = (3, 4)
x, y = posicion
print(x, y)   # 3 4

# intercambiar dos variables en una línea
a, b = 1, 2
a, b = b, a
print(a, b)   # 2 1
```

## `enumerate` — índice y valor a la vez

Cuando necesitas la posición **y** el elemento en un `for` — por ejemplo, para numerar un menú de
personajes:

```python
for i, personaje in enumerate(["Guerrero", "Maga", "Pícaro"]):
    print(i, personaje)     # 0 Guerrero / 1 Maga / 2 Pícaro
```

Puedes empezar a contar desde otro número con `start`:

## `zip` — recorrer dos listas en paralelo

Perfecto para emparejar cada personaje con su vida:

```python
personajes = ["Guerrero", "Maga"]
vidas = [120, 70]
for personaje, hp in zip(personajes, vidas):
    print(f"{personaje}: {hp}")
```

## `sorted` con `key`

`sorted` ordena cualquier colección y **devuelve una lista nueva**. El parámetro `key` dice *por qué
criterio* ordenar — por ejemplo, los objetos por la longitud de su nombre:

```python
objetos = ["espada", "arco", "hacha"]
print(sorted(objetos))            # alfabético
print(sorted(objetos, key=len))   # por longitud: ['arco', 'hacha', 'espada']
```

<Pitfall>
`sorted(lista)` devuelve una lista **nueva** y no toca la original; `lista.sort()` ordena la lista
**en el sitio** y devuelve `None`. No hagas `lista = lista.sort()` — te quedarías con `None`.
</Pitfall>

## Mini-ejercicios

<Collapsible title="1. ¿Por qué usar una tupla en vez de una lista?">

Cuando los datos **no deben cambiar** (una posición, un color fijo). Al ser inmutables son más seguras
y, además, pueden usarse como claves de un diccionario (las listas no).

</Collapsible>

<Collapsible title="2. Ordena una lista de (personaje, puntos) por los puntos, de mayor a menor.">

```python
marcador = [("Ana", 8), ("Luis", 6), ("Sara", 9)]
print(sorted(marcador, key=lambda par: par[1], reverse=True))
# [('Sara', 9), ('Ana', 8), ('Luis', 6)]
```

`key=lambda par: par[1]` ordena por el segundo elemento de cada tupla (los puntos).

</Collapsible>
