## Escribir y leer un archivo

`open(nombre, modo)` abre un archivo. Los modos habituales: `"w"` (escribir, borra lo anterior),
`"r"` (leer, por defecto), `"a"` (añadir al final). Usa siempre `with`: cierra el archivo solo.

```python
with open("guardado.txt", "w") as f:
    f.write("Partida guardada")

with open("guardado.txt") as f:
    contenido = f.read()
print(contenido)   # Partida guardada
```

<Pitfall>
El modo `"w"` **borra** el contenido anterior del archivo. Si querías conservar lo que había y añadir
al final (por ejemplo, otra línea al registro de partidas), usa el modo `"a"` (append).
</Pitfall>

## Leer línea a línea

Por ejemplo, la lista de enemigos de un nivel, uno por línea:

```python
with open("enemigos.txt", "w") as f:
    f.write("goomba\nkoopa\nboo\n")

with open("enemigos.txt") as f:
    lineas = f.readlines()      # ['goomba\n', 'koopa\n', 'boo\n']
print(len(lineas))              # 3
```

## JSON — guardar estructuras de Python

**JSON** es un formato de texto para diccionarios y listas. El módulo `json` convierte entre objetos
de Python y texto — perfecto para la ficha de un jugador:

```python
import json

jugador = {"nombre": "Link", "hp": 100}
texto = json.dumps(jugador)     # dict  → texto JSON
print(texto)                    # {"nombre": "Link", "hp": 100}

vuelta = json.loads(texto)      # texto → dict
print(vuelta["hp"])             # 100
```

## JSON + archivos = partida permanente

La combinación estrella: `json.dump` guarda directamente en un archivo y `json.load` lo recupera.
Así, tu partida (nivel, puntos, inventario) sobrevive al cierre del juego:

```python
import json

partida = {"nivel": 3, "puntos": 1200}
with open("guardado.json", "w") as f:
    json.dump(partida, f)

with open("guardado.json") as f:
    cargada = json.load(f)
print(cargada["puntos"])   # 1200
```

## Mini-ejercicios

<Collapsible title="1. ¿Cuál es la diferencia entre json.dumps y json.dump?">

`json.dumps` (con **s** de *string*) devuelve una **cadena**. `json.dump` (sin s) **escribe**
directamente en un archivo abierto. Lo mismo con `loads` (desde cadena) y `load` (desde archivo).

</Collapsible>

<Collapsible title="2. ¿Y para tablas? El módulo csv">

Para datos en filas y columnas (por ejemplo, una tabla de puntuaciones) está el módulo `csv`:

```python
import csv
with open("puntuaciones.csv", "w", newline="") as f:
    escritor = csv.writer(f)
    escritor.writerow(["jugador", "puntos"])
    escritor.writerow(["Link", 1200])
```

Se abre en Excel o Google Sheets tal cual.

</Collapsible>
