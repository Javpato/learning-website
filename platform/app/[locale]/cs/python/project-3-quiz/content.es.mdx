# Proyecto 3 — Quiz interactivo

<Accroche>« El mejor primer proyecto de datos: fácil, vistoso y muy ampliable. »</Accroche>

Tercer proyecto para tu GitHub. Ahora que dominas **listas, diccionarios y bucles**, vas a construir
un **quiz de preguntas** en la terminal. Se escribe en tu máquina y se sube a tu perfil.

## Qué vas a construir

Un cuestionario de opción múltiple que lleva la puntuación y muestra el porcentaje al final.

```text
Pregunta 1: ¿Qué significa CPU?
  A. Central Processing Unit
  B. Computer Power Unit
  C. Central Program Utility
Tu respuesta: A
¡Correcto!

...

Has acertado 4 de 5 (80%).
```

## Lo que necesitas saber

```text
listas de diccionarios     bucles for      if / else
input()                    contadores      f-strings y porcentajes
```

## La idea clave: datos separados del código

Guarda cada pregunta como un **diccionario**, y todas juntas en una **lista**. Así puedes añadir
preguntas sin tocar la lógica:

```python
preguntas = [
    {
        "pregunta": "¿Qué significa CPU?",
        "opciones": ["Central Processing Unit", "Computer Power Unit", "Central Program Utility"],
        "correcta": "A",
    },
    # ... más preguntas
]
```

## Pasos guiados

```text
1. Crea la lista `preguntas` con al menos 5 diccionarios (pregunta, opciones, correcta).
2. Lleva un contador `aciertos` en 0.
3. Recorre las preguntas con un for (usa enumerate para numerarlas):
     - muestra el enunciado y las opciones (A, B, C)
     - pide la respuesta con input() y pásala a mayúsculas
     - si coincide con "correcta", suma 1 a aciertos y di "¡Correcto!"
     - si no, muestra cuál era la correcta
4. Al final, muestra los aciertos y el porcentaje: aciertos / total * 100.
```

<Pitfall>
Para mostrar las opciones como A, B, C sin escribirlas a mano, recorre `opciones` con `enumerate` y
convierte el índice en letra. Pista: `chr(65 + i)` da `'A'`, `'B'`, `'C'`… (65 es el código de la A).
</Pitfall>

## Mejoras para GitHub

```text
- Categorías de preguntas (elige tema al empezar).
- Mezclar el orden con random.shuffle.
- Guardar la mejor puntuación.
- Mover las preguntas a un archivo aparte (preguntas.py) e importarlas.
- Temporizador por pregunta.
```
