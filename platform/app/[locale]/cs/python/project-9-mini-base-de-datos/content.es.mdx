# Proyecto 9 — Mini base de datos

<Accroche>« Construye desde cero lo que hace toda app: crear, leer, actualizar y borrar datos. »</Accroche>

Noveno proyecto para tu GitHub, y el primero al estilo *"construye tu propia X"*. Vas a programar una
**mini base de datos** que guarda registros en un archivo JSON y ofrece las cuatro operaciones
fundamentales: **CRUD**. Se escribe en tu máquina.

## Qué es CRUD

```text
Create  → crear un registro
Read    → leer / buscar registros
Update  → actualizar un registro
Delete  → borrar un registro
```

Toda aplicación seria (una red social, una tienda, tu lista de tareas) es, en el fondo, CRUD sobre
unos datos.

## Qué vas a construir

Una agenda de contactos (o notas, o libros — lo que quieras) por terminal, persistente en JSON.

```text
1) Añadir  2) Listar  3) Buscar  4) Editar  5) Borrar  6) Salir
Elige: 3
Buscar: ana
#2  Ana Pérez  —  ana@correo.com
```

## Lo que necesitas saber

```text
diccionarios y listas    json.dump / json.load     funciones
try/except               búsqueda con in / bucles  identificadores (id)
```

## Modelo de datos

Cada registro es un diccionario con un **id** único; todos van en una lista guardada en JSON:

```python
contactos = [
    {"id": 1, "nombre": "Ana Pérez", "correo": "ana@correo.com"},
    {"id": 2, "nombre": "Luis Gil",  "correo": "luis@correo.com"},
]
```

## Pasos guiados

```text
1. Carga los registros desde datos.json al arrancar (try/except FileNotFoundError -> lista vacía).
2. Una función por operación CRUD:
     - crear(datos, campos): asigna un id nuevo (el máximo actual + 1) y añade el registro.
     - leer/buscar(datos, texto): devuelve los registros cuyo nombre contenga el texto.
     - actualizar(datos, id, campos): encuentra por id y cambia sus campos.
     - borrar(datos, id): quita el registro con ese id.
3. Guarda en datos.json tras cada cambio (json.dump).
4. Un menú con while que llame a cada función.
```

<Pitfall>
El **id** debe ser único y no reutilizarse aunque borres registros. Genera el siguiente como
`max((r["id"] for r in datos), default=0) + 1`. Si reciclas ids de registros borrados, acabarás
mezclando datos.
</Pitfall>

## Mejoras para GitHub

```text
- Buscar por varios campos (nombre, correo, etiqueta).
- Ordenar los resultados.
- Exportar a CSV.
- Validar entradas (correo con "@", campos obligatorios).
- Paginar cuando haya muchos registros.
```
