# Iteradores y generadores

<Accroche>« ¿Y si un juego pudiera generar enemigos sin fin, uno a uno, sin quedarse sin memoria? »</Accroche>

Bienvenido a Python avanzado. Un **generador** produce valores **uno a uno, bajo demanda**, en vez de
crearlos todos de golpe. Es la clave para trabajar con secuencias enormes (o infinitas) gastando muy
poca memoria — como un flujo interminable de enemigos que aparecen.

## `yield` — funciones que pausan

Una función con `yield` no devuelve un valor y termina: **entrega** un valor y se **pausa**, lista
para continuar en la siguiente petición. Por ejemplo, generar las oleadas de un nivel:

```python
def oleadas(n):
    i = 1
    while i <= n:
        yield i        # entrega el número de oleada y se pausa aquí
        i += 1

for oleada in oleadas(3):
    print(oleada)      # 1, 2, 3

print(list(oleadas(4)))   # [1, 2, 3, 4]
```

## `next()` y la evaluación perezosa

Un generador se consume con `next()`. Como los valores se calculan al pedirlos, ¡puede ser infinito!
Perfecto para un spawner que suelta enemigos en posiciones cada vez más lejanas:

```python
def spawns():
    x = 0
    while True:          # bucle infinito… y no pasa nada
        yield x
        x += 2

g = spawns()
print(next(g), next(g), next(g))   # 0 2 4
```

## Expresiones generadoras

Como una comprensión, pero con paréntesis: no construye la lista, la genera al vuelo. Perfecta dentro
de `sum`, `max`, `any`… — por ejemplo, el daño total de un combo:

```python
total = sum(golpe * golpe for golpe in range(1, 4))   # 1 + 4 + 9
print(total)   # 14
```

<Pitfall>
Un generador se **agota**: una vez lo recorres, está vacío. Si necesitas los valores dos veces, o los
guardas en una lista (`list(gen)`), o creas el generador de nuevo. Un segundo `for` sobre el mismo
generador no imprime nada.
</Pitfall>

## Mini-ejercicios

<Collapsible title="1. ¿Por qué usar un generador en vez de una lista?">

Por **memoria** y **pereza**: un generador no guarda todos los valores a la vez, los produce cuando
hacen falta. Ideal para archivos enormes o flujos infinitos de enemigos, donde una lista no cabría.

</Collapsible>

<Collapsible title="2. Un generador que produzca la sucesión de Fibonacci (ideal para escalar la dificultad).">

```python
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

g = fibonacci()
print([next(g) for _ in range(7)])   # [0, 1, 1, 2, 3, 5, 8]
```

</Collapsible>
