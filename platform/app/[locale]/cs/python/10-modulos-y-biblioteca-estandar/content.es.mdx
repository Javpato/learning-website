# Módulos y biblioteca estándar

<Accroche>« No reinventes la rueda: Python trae cientos de herramientas listas para usar — muchas perfectas para un juego. »</Accroche>

Un **módulo** es un archivo de Python con código reutilizable. Ya usaste `random` (imprescindible en
los juegos). Python incluye una enorme **biblioteca estándar** ("baterías incluidas") con módulos para
matemáticas, conteos, fechas y mucho más.

## Importar

```python
import math
print(math.sqrt(144))     # 12.0  (por ejemplo, la distancia entre dos sprites)
print(math.pi)            # 3.14159...

# importar solo lo que necesitas
from math import floor, ceil
print(floor(3.7), ceil(3.2))   # 3 4
```

## `collections.Counter` — contar sin esfuerzo

¿Recuerdas contar a mano con un diccionario? `Counter` lo hace por ti — ideal para ver qué enemigo
derrotaste más veces:

```python
from collections import Counter
bajas = ["goomba", "koopa", "goomba", "boo", "goomba", "koopa"]
conteo = Counter(bajas)
print(conteo["goomba"])       # 3
print(conteo.most_common(1))  # [('goomba', 3)]  → el más repetido
```

## `datetime` — fechas y horas

Perfecto para poner fecha a un archivo de guardado:

```python
from datetime import date
d = date(2024, 7, 5)
print(d.year)      # 2024
print(d.weekday()) # 4  (0 = lunes … 4 = viernes)
```

## `itertools` — iteración de alto nivel

Por ejemplo, el marcador acumulado nivel a nivel:

```python
from itertools import accumulate
puntos = [1, 2, 3, 4]
print(list(accumulate(puntos)))   # [1, 3, 6, 10]  (marcador acumulado)
```

## Tus propios módulos

Cualquier archivo `.py` es un módulo. Si tienes `enemigos.py` con una función `crear_enemigo`, desde
otro archivo haces `from enemigos import crear_enemigo`. Un patrón muy común al final de un módulo
ejecutable:

```python
def main():
    print("¡A jugar!")

if __name__ == "__main__":
    main()    # solo se ejecuta si corres ESTE archivo directamente
```

<Pitfall>
`import math` te da el módulo entero (usas `math.sqrt`); `from math import sqrt` trae solo esa función
(usas `sqrt` a secas). No mezcles hasta el punto de no saber de dónde viene cada nombre — la
legibilidad manda.
</Pitfall>
