# Módulos y biblioteca estándar

<Accroche>« No reinventes la rueda: Python trae cientos de herramientas listas para usar. »</Accroche>

Un **módulo** es un archivo de Python con código reutilizable. Ya usaste `random`. Python incluye una
enorme **biblioteca estándar** ("baterías incluidas") con módulos para fechas, matemáticas, conteos
y mucho más.

## Importar

```python
import math
print(math.sqrt(144))     # 12.0
print(math.pi)            # 3.14159...

# importar solo lo que necesitas
from math import floor, ceil
print(floor(3.7), ceil(3.2))   # 3 4
```

print(math.sqrt(144))

## `collections.Counter` — contar sin esfuerzo

¿Recuerdas contar a mano con un diccionario? `Counter` lo hace por ti:

```python
from collections import Counter
votos = ["a", "b", "a", "c", "a", "b"]
conteo = Counter(votos)
print(conteo["a"])            # 3
print(conteo.most_common(1))  # [('a', 3)]  → el más repetido
```

## `datetime` — fechas y horas

```python
from datetime import date
d = date(2024, 7, 5)
print(d.year)      # 2024
print(d.weekday()) # 4  (0 = lunes … 4 = viernes)
```

## `itertools` — iteración de alto nivel

```python

print(list(accumulate([1, 2, 3, 4])))   # [1, 3, 6, 10]  (sumas acumuladas)
```

## Tus propios módulos

Cualquier archivo `.py` es un módulo. Si tienes `utilidades.py` con una función `saludar`, desde otro
archivo haces `from utilidades import saludar`. Un patrón muy común al final de un módulo ejecutable:

```python
def main():
    print("¡Hola!")

if __name__ == "__main__":
    main()    # solo se ejecuta si corres ESTE archivo directamente
```

<Pitfall>
`import math` te da el módulo entero (usas `math.sqrt`); `from math import sqrt` trae solo esa función
(usas `sqrt` a secas). No mezcles hasta el punto de no saber de dónde viene cada nombre — la
legibilidad manda.
</Pitfall>
