# Modules et bibliothèque standard

<Accroche>« Ne réinvente pas la roue : Python apporte des centaines d'outils prêts à l'emploi — beaucoup parfaits pour un jeu. »</Accroche>

Un **module** est un fichier Python avec du code réutilisable. Tu as déjà utilisé `random`
(indispensable dans les jeux). Python inclut une énorme **bibliothèque standard** (« piles
incluses ») avec des modules pour les maths, les comptages, les dates et bien plus.

## Importer

```python
import math
print(math.sqrt(144))     # 12.0  (par exemple, la distance entre deux sprites)
print(math.pi)            # 3.14159...

# importer seulement ce dont tu as besoin
from math import floor, ceil
print(floor(3.7), ceil(3.2))   # 3 4
```

## `collections.Counter` — compter sans effort

Tu te souviens du comptage à la main avec un dictionnaire ? `Counter` le fait pour toi — idéal pour
voir quel ennemi tu as vaincu le plus :

```python
from collections import Counter
bajas = ["goomba", "koopa", "goomba", "boo", "goomba", "koopa"]
conteo = Counter(bajas)
print(conteo["goomba"])       # 3
print(conteo.most_common(1))  # [('goomba', 3)]  → le plus répété
```

## `datetime` — dates et heures

Parfait pour dater un fichier de sauvegarde :

```python
from datetime import date
d = date(2024, 7, 5)
print(d.year)      # 2024
print(d.weekday()) # 4  (0 = lundi … 4 = vendredi)
```

## `itertools` — itération de haut niveau

Par exemple, le score cumulé niveau par niveau :

```python
from itertools import accumulate
puntos = [1, 2, 3, 4]
print(list(accumulate(puntos)))   # [1, 3, 6, 10]  (score cumulé)
```

## Tes propres modules

N'importe quel fichier `.py` est un module. Si tu as `enemigos.py` avec une fonction `crear_enemigo`,
depuis un autre fichier tu fais `from enemigos import crear_enemigo`. Un motif très courant à la fin
d'un module exécutable :

```python
def main():
    print("On joue !")

if __name__ == "__main__":
    main()    # ne s'exécute que si tu lances CE fichier directement
```

<Pitfall>
`import math` te donne le module entier (tu utilises `math.sqrt`) ; `from math import sqrt` n'apporte
que cette fonction (tu utilises `sqrt` tout court). Ne mélange pas au point de ne plus savoir d'où
vient chaque nom — la lisibilité prime.
</Pitfall>
