# Comprehensions

<Accroche>« A loop that builds a list, boiled down to one readable line — like computing the damage of each hit in a combo. »</Accroche>

Very often we build a list by walking over another one: the living enemies, the damage of each hit,
the items you can afford. Python has a short, elegant way to do it: the **list comprehension**.

## From loop to comprehension

Watch how this loop that computes a combo's damage (each hit hurts more) transforms:

```python
# The long way
daño = []
for n in range(1, 6):
    daño.append(n ** 2)

# The same idea, in one line
daño = [n ** 2 for n in range(1, 6)]
print(daño)   # [1, 4, 9, 16, 25]
```

It reads almost like English: *"n squared, for each n in the range 1 to 5"*.

## With a condition (filtering)

Add an `if` at the end to **keep only some** elements. For example, which enemies are still alive (hp
greater than 0):

```python
hp_enemigos = [0, 12, 0, 8, 30]
vivos = [hp for hp in hp_enemigos if hp > 0]
print(vivos)   # [12, 8, 30]
```

## Transforming

Comprehensions work for any transformation, not just numbers. For example, uppercasing the names of
the shop's items:

```python
objetos = ["espada", "escudo"]
mayus = [o.upper() for o in objetos]
print(mayus)   # ['ESPADA', 'ESCUDO']
```

{/* sol:
objetos = ["espada", "escudo"]

## Dictionary and set comprehensions

The same idea works with `{}`. For example, the experience each level costs:

```python
# dictionary: level -> xp needed
xp = {n: n * 100 for n in range(1, 4)}
print(xp)   # {1: 100, 2: 200, 3: 300}

# set: distinct enemy types, no duplicates
oleada = ["fuego", "agua", "fuego", "planta"]
tipos = {t for t in oleada}
print(tipos)   # {'fuego', 'agua', 'planta'}
```

{/* sol:

<Pitfall>
A comprehension is great when it fits comfortably on one line. If you cram in several conditions and
nested loops until it's unreadable, use a normal `for` instead: clear code beats short code.
</Pitfall>
