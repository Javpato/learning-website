# Compréhensions

<Accroche>« Une boucle qui construit une liste, condensée en une ligne lisible — comme calculer les dégâts de chaque coup d'un combo. »</Accroche>

Très souvent on crée une liste en parcourant une autre : les ennemis vivants, les dégâts de chaque
coup, les objets que tu peux te payer. Python a une façon courte et élégante de le faire : la
**compréhension de liste**.

## De la boucle à la compréhension

Regarde comment cette boucle qui calcule les dégâts d'un combo (chaque coup fait plus mal) se
transforme :

```python
# La forme longue
daño = []
for n in range(1, 6):
    daño.append(n ** 2)

# La même idée, en une ligne
daño = [n ** 2 for n in range(1, 6)]
print(daño)   # [1, 4, 9, 16, 25]
```

Ça se lit presque comme du français : *« n au carré, pour chaque n dans l'intervalle 1 à 5 »*.

{/* sol:
daño = [n ** 2 for n in range(1, 6)]
print(daño)
*/}

## Avec une condition (filtrer)

Ajoute un `if` à la fin pour **ne garder que certains** éléments. Par exemple, quels ennemis sont
encore vivants (hp supérieur à 0) :

```python
hp_enemigos = [0, 12, 0, 8, 30]
vivos = [hp for hp in hp_enemigos if hp > 0]
print(vivos)   # [12, 8, 30]
```

{/* sol:
hp_enemigos = [0, 12, 0, 8, 30]
vivos = [hp for hp in hp_enemigos if hp > 0]
print(vivos)

## Transformer

Les compréhensions servent à n'importe quelle transformation, pas seulement les nombres. Par exemple,
mettre en majuscules les noms des objets de la boutique :

```python
objetos = ["espada", "escudo"]
mayus = [o.upper() for o in objetos]
print(mayus)   # ['ESPADA', 'ESCUDO']
```

{/* sol:
objetos = ["espada", "escudo"]
print([o.upper() for o in objetos])
*/}

## Compréhensions de dictionnaire et d'ensemble

La même idée marche avec `{}`. Par exemple, l'expérience que coûte chaque niveau :

```python
# dictionnaire : niveau -> xp nécessaire
xp = {n: n * 100 for n in range(1, 4)}
print(xp)   # {1: 100, 2: 200, 3: 300}

# ensemble : types d'ennemi distincts, sans doublons
oleada = ["fuego", "agua", "fuego", "planta"]
tipos = {t for t in oleada}
print(tipos)   # {'fuego', 'agua', 'planta'}
```

{/* sol:
xp = {n: n * 100 for n in range(1, 4)}
print(xp)
*/}

<Pitfall>
Une compréhension est géniale quand elle tient à l'aise sur une ligne. Si tu y mets plusieurs
conditions et des boucles imbriquées jusqu'à la rendre illisible, utilise plutôt un `for` normal : le
code clair l'emporte sur le code court.
</Pitfall>
