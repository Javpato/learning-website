# Comprensiones

<Accroche>« Un bucle que construye una lista, condensado en una línea legible — como calcular el daño de cada golpe de un combo. »</Accroche>

Muchísimas veces creamos una lista recorriendo otra: los enemigos vivos, el daño de cada golpe, los
objetos que puedes pagar. Python tiene una forma corta y elegante de hacerlo: la **comprensión de
listas** (*list comprehension*).

## De bucle a comprensión

Mira cómo se transforma este bucle que calcula el daño de un combo (cada golpe pega más):

```python
# La forma larga
daño = []
for n in range(1, 6):
    daño.append(n ** 2)

# La misma idea, en una línea
daño = [n ** 2 for n in range(1, 6)]
print(daño)   # [1, 4, 9, 16, 25]
```

Se lee casi como en español: *"n al cuadrado, para cada n en el rango 1 a 5"*.

## Con condición (filtrar)

Añade un `if` al final para **quedarte solo con algunos** elementos. Por ejemplo, qué enemigos siguen
vivos (hp mayor que 0):

```python
hp_enemigos = [0, 12, 0, 8, 30]
vivos = [hp for hp in hp_enemigos if hp > 0]
print(vivos)   # [12, 8, 30]
```

## Transformar

Las comprensiones sirven para cualquier transformación, no solo números. Por ejemplo, poner en
mayúsculas los nombres de los objetos de la tienda:

```python
objetos = ["espada", "escudo"]
mayus = [o.upper() for o in objetos]
print(mayus)   # ['ESPADA', 'ESCUDO']
```

{/* sol:

## Comprensiones de diccionario y conjunto

La misma idea funciona con `{}`. Por ejemplo, la experiencia que cuesta cada nivel:

```python
# diccionario: nivel -> xp necesaria
xp = {n: n * 100 for n in range(1, 4)}
print(xp)   # {1: 100, 2: 200, 3: 300}

# conjunto: tipos de enemigo distintos, sin duplicados
oleada = ["fuego", "agua", "fuego", "planta"]
tipos = {t for t in oleada}
print(tipos)   # {'fuego', 'agua', 'planta'}
```

{/* sol:
xp = {n: n * 100 for n in range(1, 4)}

<Pitfall>
Una comprensión es genial cuando cabe cómoda en una línea. Si le metes varias condiciones y bucles
anidados hasta volverla ilegible, mejor usa un `for` normal: el código claro gana al código corto.
</Pitfall>
