## Diseño con clases

Modela el mundo como objetos que se relacionan (composición):

```python
class Habitacion:
    def __init__(self, descripcion):
        self.descripcion = descripcion
        self.salidas = {}       # "norte" -> otra Habitacion
        self.objetos = []       # cosas que se pueden coger

class Juego:
    def __init__(self):
        self.actual = None      # habitación donde está el jugador
        self.inventario = []
```

## Pasos guiados

```text
1. Crea varias Habitacion y conéctalas por sus salidas (bosque.salidas["norte"] = castillo).
2. Bucle principal (while): muestra la habitación actual y sus salidas, y lee un comando con input().
3. Analiza el comando: sepáralo con split() en verbo + resto ("ir norte" -> "ir", "norte").
4. Implementa los verbos con if/elif (o un diccionario verbo -> función):
     - "ir <dirección>": si existe esa salida, cambia self.actual; si no, avisa.
     - "coger <objeto>": muévelo de la habitación al inventario.
     - "inventario": muestra lo que llevas.
     - "salir": termina el juego.
5. Añade una condición de victoria (llegar a una sala, o tener cierto objeto).
```

<Pitfall>
No llenes el bucle principal de `if/elif` interminables. Un diccionario que asocia cada verbo con la
función que lo maneja (`comandos = {"ir": self.mover, "coger": self.coger, ...}`) mantiene el código
ordenado y hace trivial añadir verbos nuevos.
</Pitfall>
