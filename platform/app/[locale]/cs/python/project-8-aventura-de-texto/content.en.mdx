## Design with classes

Model the world as objects that relate to each other (composition):

```python
class Habitacion:
    def __init__(self, descripcion):
        self.descripcion = descripcion
        self.salidas = {}       # "norte" -> another Habitacion
        self.objetos = []       # things you can pick up

class Juego:
    def __init__(self):
        self.actual = None      # room where the player is
        self.inventario = []
```

## Guided steps

```text
1. Create several Habitacion and connect them by their exits (bosque.salidas["norte"] = castillo).
2. Main loop (while): show the current room and its exits, and read a command with input().
3. Parse the command: split it with split() into verb + rest ("ir norte" -> "ir", "norte").
4. Implement the verbs with if/elif (or a dictionary verb -> function):
     - "ir <direction>": if that exit exists, change self.actual; if not, warn.
     - "coger <object>": move it from the room to the inventory.
     - "inventario": show what you're carrying.
     - "salir": end the game.
5. Add a win condition (reach a room, or hold a certain object).
```

<Pitfall>
Don't fill the main loop with endless `if/elif`. A dictionary mapping each verb to the function that
handles it (`comandos = {"ir": self.mover, "coger": self.coger, ...}`) keeps the code tidy and makes
adding new verbs trivial.
</Pitfall>
