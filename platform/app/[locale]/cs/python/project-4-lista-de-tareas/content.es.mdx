# Proyecto 4 — Lista de tareas

<Accroche>« Una app pequeña pero útil de verdad: gestiona tus tareas desde la terminal. »</Accroche>

Cuarto proyecto para tu GitHub. Vas a construir una **lista de tareas** (*to-do list*) con un menú:
añadir, ver, completar y borrar tareas. La versión base guarda las tareas **en memoria**; guardarlas
en disco será tu primera mejora (lo verás a fondo en el Módulo 3).

## Qué vas a construir

```text
==== MIS TAREAS ====
1. [ ] Comprar pan
2. [x] Estudiar Python
3. [ ] Llamar a Ana

1) Añadir  2) Completar  3) Borrar  4) Salir
Elige una opción: 1
Nueva tarea: Regar las plantas
Añadida.
```

## Lo que necesitas saber

```text
listas y diccionarios      bucles while (menú)      funciones
if / elif / else           input()                  enumerate
```

## Modelo de datos

Cada tarea es un **diccionario** con su texto y si está hecha; todas van en una **lista**:

```python
tareas = [
    {"texto": "Comprar pan", "hecha": False},
    {"texto": "Estudiar Python", "hecha": True},
]
```

## Pasos guiados

```text
1. Empieza con la lista `tareas` (vacía o con un par de ejemplos).
2. Escribe funciones pequeñas, una por acción:
     - mostrar(tareas): recorre con enumerate e imprime [x] o [ ] según "hecha"
     - añadir(tareas, texto): añade un diccionario nuevo con hecha=False
     - completar(tareas, numero): pon "hecha" = True en esa posición
     - borrar(tareas, numero): quita esa tarea de la lista
3. Bucle principal con while: muestra el menú, lee la opción y llama a la función.
4. Sal del bucle cuando el usuario elija «Salir».
```

<Pitfall>
El usuario cuenta desde **1** (la tarea 1, 2, 3…), pero las listas empiezan en **0**. Cuando recibas
el número, resta 1 antes de usarlo como índice: `tareas[numero - 1]`. Y valida que exista.
</Pitfall>

## Mejoras para GitHub

```text
- Guardar las tareas en un archivo JSON y cargarlas al arrancar (¡Módulo 3!).
- Fechas de vencimiento y prioridades.
- Marcar/desmarcar como completada.
- Filtrar: ver solo las pendientes.
- Contador de tareas hechas vs. pendientes.
```
