# Clases y objetos

<Accroche>« Una clase es un molde. Cada objeto que creas con él es una pieza con vida propia. »</Accroche>

Hasta ahora tus datos y tus funciones iban por separado. La **programación orientada a objetos** los
junta: una **clase** describe *qué datos* tiene algo y *qué puede hacer*. Cada ejemplar concreto es un
**objeto** (o *instancia*).

## Tu primera clase

```python
class Perro:
    def __init__(self, nombre):
        self.nombre = nombre       # un atributo (dato del objeto)

    def ladrar(self):              # un método (algo que el objeto hace)
        return self.nombre + " dice guau"

toby = Perro("Toby")               # creamos un objeto
print(toby.nombre)                 # Toby
print(toby.ladrar())               # Toby dice guau
```

- `__init__` es el **constructor**: se ejecuta al crear el objeto y prepara sus atributos.
- `self` es **el propio objeto**. Siempre es el primer parámetro de los métodos, y con él accedes a
  sus atributos (`self.nombre`).

## Estado que cambia

Los objetos **recuerdan** su estado entre llamadas a sus métodos:

```python
class Contador:
    def __init__(self):
        self.valor = 0

    def incrementar(self):
        self.valor += 1

c = Contador()
c.incrementar()
c.incrementar()
print(c.valor)   # 2
```

{/* sol:
class Contador:
    def __init__(self):
        self.valor = 0
    def incrementar(self):
        self.valor += 1

c = Contador()
c.incrementar()
c.incrementar()
print(c.valor)
*/}

<Pitfall>
Olvidar `self` es el error clásico. Dentro de un método, `self.valor` es el atributo del objeto;
`valor` a secas sería una variable local que se pierde. Y todo método lleva `self` como primer
parámetro, aunque al llamarlo no lo pases (`c.incrementar()`, no `c.incrementar(c)`).
</Pitfall>

## Varios objetos, moldes independientes

Cada objeto tiene **sus propios** atributos:

```python
class Rectangulo:
    def __init__(self, base, altura):
        self.base = base
        self.altura = altura

    def area(self):
        return self.base * self.altura

r1 = Rectangulo(4, 3)
r2 = Rectangulo(10, 2)
print(r1.area(), r2.area())   # 12 20
```

## Mini-ejercicios

<Collapsible title="1. ¿Qué diferencia hay entre una clase y un objeto?">

La **clase** es el molde (la receta): `Perro`. El **objeto** es una pieza concreta creada con ese
molde: `toby = Perro("Toby")`. De una clase puedes crear muchos objetos independientes.

</Collapsible>

<Collapsible title="2. Una clase CuentaBancaria con depositar y retirar.">

```python
class CuentaBancaria:
    def __init__(self, saldo=0):
        self.saldo = saldo
    def depositar(self, cantidad):
        self.saldo += cantidad
    def retirar(self, cantidad):
        if cantidad <= self.saldo:
            self.saldo -= cantidad

c = CuentaBancaria(100)
c.depositar(50)
c.retirar(30)
print(c.saldo)   # 120
```

</Collapsible>
