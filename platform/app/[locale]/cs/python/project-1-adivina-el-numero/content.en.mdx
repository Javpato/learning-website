## What you'll build

A terminal game: the computer picks a secret number between 1 and 100 and you have to guess it. On each
attempt the program tells you whether you were too low or too high.

```text
I'm thinking of a number between 1 and 100.
Your guess: 50
Too high.
Your guess: 25
Too low.
Your guess: 32
Correct! You did it in 3 attempts.
```

```text

while loops       random.randint()
```

## Set up your machine

1. Check that you have Python: in a terminal type `python --version` (or `python3 --version`).
2. Create a folder for the project, for example `adivina-el-numero/`.
3. Inside, create a file `main.py`.
4. To run it, from that folder: `python main.py`.

## Guided steps

Don't copy a whole program: build it bit by bit and **run it after each step** to see that it works.
This is the recipe (in words, not in code):

```text
1. Import random and pick the secret number with random.randint(1, 100).
2. Welcome the player with a print.
3. Create an attempts counter at 0.
4. Repeat with a while (as long as it's not guessed):
     - ask for a guess and convert it to an integer with int(input(...))
     - add 1 to the counter
     - if the guess is LOWER than the secret  -> print "Too low."
     - if it's HIGHER than the secret          -> print "Too high."
     - if it's EQUAL                           -> congratulate and show the attempts, and leave the loop
```

To leave the loop when guessed, you can use `break`, or a `bool` variable that controls the `while`
condition. Either one is fine.

Here's a **test bench** to experiment with comparing a single guess (with the secret fixed at 42). It's
not the full game — it's just so you can see the logic of the three branches:

<Pitfall>
The most common error: forgetting to convert the guess with `int(...)`. If you compare the **string**
returned by `input()` with a number, Python will raise a `TypeError`. Always convert as you read:
`intento = int(input("Your guess: "))`.
</Pitfall>

## Upgrades for GitHub

When the basic version works, push that first commit and then add upgrades (each one is a good new
commit):

```text
- Difficulty levels (easy 1–50, hard 1–500).
- An attempts limit: if you run out, you lose.
- A scoring system based on the attempts used.
- A play-again option without restarting the program.
- Validate the input (what if the user doesn't type a number?).
- A clear README.md (template below).
```

## Push it to your GitHub

From the project folder:

```bash
git init
git add .
git commit -m "First project: Guess the Number game"
```

Then create an empty repository on GitHub and connect it:

```bash
git remote add origin https://github.com/YOUR-USERNAME/adivina-el-numero.git
git branch -M main
git push -u origin main
```
