# Proyecto 1 — Adivina el número

<Accroche>« Ya sabes lo suficiente para construir un juego de verdad. Este lo escribes tú, en tu máquina. »</Accroche>

Este es tu **primer proyecto para GitHub**. A diferencia de los ejercicios del capítulo, este **no se
escribe en la web**: lo programas en tu propio ordenador y lo subes a tu perfil de GitHub. Aquí tienes
la guía, los pasos y las pistas — pero el código lo escribes **tú**. Así es como se aprende de verdad
(y como se construye un portafolio).

Usa **solo** lo del capítulo 1: `print`, variables, `input` + `int()`, `if/elif/else`, `while` y
`random.randint`.

## Qué vas a construir

Un juego de terminal: el ordenador elige un número secreto entre 1 y 100 y tú tienes que adivinarlo.
En cada intento el programa te dice si te has quedado corto o te has pasado.

```text
Estoy pensando en un número entre 1 y 100.
Tu intento: 50
Demasiado alto.
Tu intento: 25
Demasiado bajo.
Tu intento: 32
¡Correcto! Lo lograste en 3 intentos.
```

## Lo que necesitas saber

```text
print()          input()          int()
variables        if / elif / else
bucles while     random.randint()
```

Todo esto lo viste en el capítulo 1. Si algo se te ha olvidado, vuelve un momento — no pasa nada.

## Prepara tu máquina

1. Comprueba que tienes Python: en una terminal escribe `python --version` (o `python3 --version`).
2. Crea una carpeta para el proyecto, por ejemplo `adivina-el-numero/`.
3. Dentro, crea un archivo `main.py`.
4. Para ejecutarlo, desde esa carpeta: `python main.py`.

## Pasos guiados

No copies un programa entero: constrúyelo poco a poco y **ejecútalo después de cada paso** para ver
que funciona. Esta es la receta (en palabras, no en código):

```text
1. Importa random y elige el número secreto con random.randint(1, 100).
2. Da la bienvenida con un print.
3. Crea un contador de intentos en 0.
4. Repite con un while (mientras no se acierte):
     - pide un intento y conviértelo a entero con int(input(...))
     - suma 1 al contador
     - si el intento es MENOR que el secreto  -> imprime "Demasiado bajo."
     - si es MAYOR que el secreto             -> imprime "Demasiado alto."
     - si es IGUAL                            -> felicita e indica los intentos, y sal del bucle
```

Para salir del bucle al acertar puedes usar `break`, o una variable de tipo `bool` que controle la
condición del `while`. Cualquiera de las dos está bien.

Aquí tienes un **banco de pruebas** para experimentar con la comparación de un solo intento (con el
secreto fijo en 42). No es el juego completo — es solo para que veas la lógica de las tres ramas:

<PyExercise

  starter={`secreto = 42
intento = 30
if intento < secreto:

<Pitfall>
El error más común: olvidar convertir el intento con `int(...)`. Si comparas la **cadena** que
devuelve `input()` con un número, Python lanzará un `TypeError`. Convierte siempre al leer:
`intento = int(input("Tu intento: "))`.
</Pitfall>

## Mejoras para GitHub

Cuando la versión básica funcione, sube ese primer commit y luego ve añadiendo mejoras (cada una es un
buen commit nuevo):

```text
- Niveles de dificultad (fácil 1–50, difícil 1–500).
- Límite de intentos: si se acaban, pierdes.
- Sistema de puntuación según los intentos usados.
- Opción de volver a jugar sin reiniciar el programa.
- Validar la entrada (¿y si el usuario no escribe un número?).
- Un README.md claro (plantilla más abajo).
```
