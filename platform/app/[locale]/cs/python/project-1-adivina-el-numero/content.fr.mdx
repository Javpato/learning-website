## Ce que tu vas construire

Un jeu de terminal : l'ordinateur choisit un nombre secret entre 1 et 100 et tu dois le deviner. À
chaque essai, le programme te dit si tu es trop bas ou trop haut.

```text
Je pense à un nombre entre 1 et 100.
Ton essai : 50
Trop haut.
Ton essai : 25
Trop bas.
Ton essai : 32
Correct ! Tu as réussi en 3 essais.
```

## Ce que tu dois savoir

```text
print()          input()          int()
variables        if / elif / else
boucles while     random.randint()
```

Tu as vu tout ça dans le chapitre 1. Si tu as oublié quelque chose, reviens un instant — pas de souci.

## Prépare ta machine

1. Vérifie que tu as Python : dans un terminal, tape `python --version` (ou `python3 --version`).
2. Crée un dossier pour le projet, par exemple `adivina-el-numero/`.
3. Dedans, crée un fichier `main.py`.
4. Pour l'exécuter, depuis ce dossier : `python main.py`.

## Étapes guidées

Ne copie pas un programme entier : construis-le petit à petit et **exécute-le après chaque étape** pour
voir qu'il marche. Voici la recette (en mots, pas en code) :

```text
1. Importe random et choisis le nombre secret avec random.randint(1, 100).
2. Souhaite la bienvenue avec un print.
3. Crée un compteur d'essais à 0.
4. Répète avec un while (tant que ce n'est pas deviné) :
     - demande un essai et convertis-le en entier avec int(input(...))
     - ajoute 1 au compteur
     - si l'essai est PLUS BAS que le secret  -> affiche "Trop bas."
     - s'il est PLUS HAUT que le secret        -> affiche "Trop haut."
     - s'il est ÉGAL                           -> félicite et indique les essais, et sors de la boucle
```

Pour sortir de la boucle une fois deviné, tu peux utiliser `break`, ou une variable de type `bool` qui
contrôle la condition du `while`. L'une ou l'autre convient.

Voici un **banc d'essai** pour expérimenter la comparaison d'un seul essai (avec le secret fixé à 42).
Ce n'est pas le jeu complet — c'est juste pour que tu voies la logique des trois branches :

<PyExercise

intento = 30

<Pitfall>
L'erreur la plus courante : oublier de convertir l'essai avec `int(...)`. Si tu compares la **chaîne**
renvoyée par `input()` avec un nombre, Python lèvera une `TypeError`. Convertis toujours à la lecture :
`intento = int(input("Ton essai : "))`.
</Pitfall>

## Améliorations pour GitHub

Quand la version de base marche, pousse ce premier commit puis ajoute des améliorations (chacune est un
bon nouveau commit) :

