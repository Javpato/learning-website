## The Pygame game loop

Every Pygame game has the same structure. Learn it and you'll reuse it forever:

```python
import pygame

pygame.init()
pantalla = pygame.display.set_mode((600, 400))
reloj = pygame.time.Clock()

jugando = True
while jugando:
    for evento in pygame.event.get():          # 1) events (close, keys)
        if evento.type == pygame.QUIT:
            jugando = False

    # 2) update the state (move the snake, check collisions)

    pantalla.fill((0, 0, 0))                    # 3) draw: background…
    # … and here the snake's and the food's rectangles
    pygame.display.flip()                       # show the frame

    reloj.tick(10)                              # 4) 10 frames per second

pygame.quit()
```

## Guided steps

```text
1. Window and game loop (the skeleton above).
2. Represent the snake as a LIST of (x, y) positions; the head is the first element.
3. Direction: with the arrows, change the movement vector (dx, dy). Each frame,
   add a new head in front and remove the tail (unless it has eaten).
4. Food: a random position. If the head lands on it, DON'T remove the tail (the snake grows)
   and place new food.
5. Game over: if the head leaves the screen or touches its own body, show "game over".
6. Draw each segment as a pygame.Rect and keep the score.
```

<Pitfall>
The snake moves **on its own**, one step per frame; the arrows only change the **direction**, they don't
move it at once. Store the direction in a `(dx, dy)` vector and apply it each turn of the loop. And
control the speed with `reloj.tick(FPS)`, not with `sleep`.
</Pitfall>
