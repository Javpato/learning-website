## Qué vas a construir

Una serpiente que se mueve por una cuadrícula, come comida (y crece), y pierde si choca con la pared o
consigo misma. Con puntuación y pantalla de "game over".

## Lo que necesitas saber

```text
el bucle de juego de Pygame     dibujar rectángulos      teclado (flechas)
listas (el cuerpo de la serpiente)   colisiones          FPS (velocidad)
```

## El bucle de juego de Pygame

Todo juego de Pygame tiene la misma estructura. Apréndela y la reutilizarás siempre:

```python
import pygame

pygame.init()
pantalla = pygame.display.set_mode((600, 400))
reloj = pygame.time.Clock()

jugando = True
while jugando:
    for evento in pygame.event.get():          # 1) eventos (cerrar, teclas)
        if evento.type == pygame.QUIT:
            jugando = False

    # 2) actualizar el estado (mover la serpiente, comprobar colisiones)

    pantalla.fill((0, 0, 0))                    # 3) dibujar: fondo…
    # … y aquí los rectángulos de la serpiente y la comida
    pygame.display.flip()                       # muestra el fotograma

    reloj.tick(10)                              # 4) 10 fotogramas por segundo

pygame.quit()
```

## Pasos guiados

```text
1. Ventana y bucle de juego (el esqueleto de arriba).
2. Representa la serpiente como una LISTA de posiciones (x, y); la cabeza es el primer elemento.
3. Dirección: con las flechas, cambia el vector de movimiento (dx, dy). Cada fotograma,
   añade una cabeza nueva delante y quita la cola (a menos que haya comido).
4. Comida: una posición al azar. Si la cabeza cae en ella, NO quites la cola (la serpiente crece)
   y coloca comida nueva.
5. Fin del juego: si la cabeza sale de la pantalla o toca su propio cuerpo, muestra "game over".
6. Dibuja cada segmento como un pygame.Rect y lleva la puntuación.
```

<Pitfall>
La serpiente se mueve **sola**, un paso por fotograma; las flechas solo cambian la **dirección**, no
mueven de golpe. Guarda la dirección en un vector `(dx, dy)` y aplícalo en cada vuelta del bucle. Y
controla la velocidad con `reloj.tick(FPS)`, no con `sleep`.
</Pitfall>
