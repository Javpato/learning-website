# Setup para proyectos

<Accroche>« Antes de tu primer proyecto, prepara tu equipo una sola vez. Aquí tienes cada paso. »</Accroche>

Los capítulos se ejecutan en el navegador, pero los **proyectos** los escribes en tu propio ordenador
y los subes a **GitHub**. Esta guía te prepara para ello — de forma **muy guiada** — y solo la haces
**una vez**. Instalaremos tres cosas: **Git**, **Python** y **VS Code** (el editor).

> Elige tu sistema en las pestañas de más abajo (Linux o Windows). El resto de pasos son iguales para
> los dos.

## ¿Qué es GitHub? (y Git)

Son dos cosas distintas que se usan juntas:

- **Git** es un programa que guarda el **historial** de tu código: cada versión, qué cambiaste y
  cuándo. Es como un "guardado" infinito con el que puedes volver atrás.
- **GitHub** es una **web** donde subes ese código para guardarlo en la nube, compartirlo y enseñarlo.
  Es, además, tu **portafolio**: cuando alguien quiere ver lo que sabes hacer, mira tu GitHub.

En resumen: programas en tu ordenador → Git guarda las versiones → GitHub las publica online.

## Paso 1 · Crea tu cuenta de GitHub

Esto es igual en cualquier sistema:

1. Entra en [github.com](https://github.com).
2. Pulsa **Sign up** (Registrarse).
3. Escribe tu **correo**, una **contraseña** y un **nombre de usuario** (será parte de la dirección de
   tus proyectos, p. ej. `github.com/tu-usuario`).
4. Verifica tu correo con el código que te envían.
5. ¡Listo! Ya tienes cuenta. Guarda bien tu usuario y contraseña.

## Paso 2 · Instala las herramientas

<Tabs>

<Tab label="🐧 Linux">

### 2.1 · Git

Abre una **terminal** e instala Git con el gestor de paquetes de tu sistema:

```bash
sudo apt update
sudo apt install git        # Debian / Ubuntu / Mint
# Fedora:        sudo dnf install git
# Arch/Manjaro:  sudo pacman -S git
```

Comprueba que quedó instalado (debe mostrar un número de versión):

```bash
git --version
```

### 2.2 · Python

Casi todas las distribuciones ya traen Python 3. Compruébalo:

```bash
python3 --version
```

Si no aparece, instálalo (junto con `pip` y `venv`, que usarás en los proyectos):

```bash
sudo apt install python3 python3-pip python3-venv
```

> En Linux se usa `python3` y `pip3` (no `python` a secas).

### 2.3 · VS Code

La forma más rápida es con snap:

```bash
sudo snap install code --classic
```

¿No usas snap? Descarga el paquete **.deb** desde
[code.visualstudio.com](https://code.visualstudio.com) e instálalo:

```bash
sudo dpkg -i ~/Descargas/code_*.deb
```

Ábrelo escribiendo `code` en la terminal o desde el menú de aplicaciones.

</Tab>

<Tab label="🪟 Windows">

### 2.1 · Git

1. Entra en [git-scm.com/download/win](https://git-scm.com/download/win); la descarga empieza sola.
2. Ejecuta el instalador y pulsa **Next** en todas las pantallas (las opciones por defecto están bien).
   Incluye una app llamada **Git Bash**, una terminal muy cómoda.
3. Abre **PowerShell** (busca "PowerShell" en el menú de inicio) y comprueba:

```powershell
git --version
```

### 2.2 · Python

1. Entra en [python.org/downloads](https://www.python.org/downloads) y pulsa el botón amarillo
   **Download Python 3.x**.
2. Ejecuta el instalador y — **muy importante** — marca abajo la casilla
   **"Add python.exe to PATH"** antes de continuar.
3. Pulsa **Install Now** y espera a que termine.
4. Abre **PowerShell** y comprueba:

```powershell
python --version
```

> Si dice que no encuentra `python`, es que olvidaste marcar "Add to PATH": vuelve a ejecutar el
> instalador, elige **Modify** y activa esa casilla.

### 2.3 · VS Code

1. Entra en [code.visualstudio.com](https://code.visualstudio.com) y pulsa **Download for Windows**.
2. Ejecuta el instalador. Acepta el acuerdo y **marca "Add to PATH"** (y, si quieres, "Abrir con Code").
3. Termina y abre **VS Code**.

</Tab>

</Tabs>

## Paso 3 · Presenta a Git quién eres

Git etiqueta cada guardado con tu nombre y correo. Configúralo una vez (usa el **mismo correo** que en
GitHub). Sirve el mismo comando en Linux y Windows:

```bash
git config --global user.name "Tu Nombre"
git config --global user.email "tu-correo@ejemplo.com"
```

## Paso 4 · Prepara VS Code para Python

1. Abre VS Code.
2. Pulsa el icono de **Extensiones** en la barra lateral (o `Ctrl+Shift+X`).
3. Busca **Python** e instala la de **Microsoft** (la primera, con millones de descargas).
4. Con eso VS Code ya sabe ejecutar y entender tu código Python (autocompletado, botón ▶ para
   ejecutar, avisos de errores…).

## Paso 5 · Tu primer flujo completo

Vamos a crear un proyecto minúsculo, ejecutarlo y subirlo a GitHub. Este es el flujo que repetirás en
**todos** los proyectos del curso.

**a) Crea la carpeta y ábrela en VS Code**

```bash
mkdir mi-proyecto
cd mi-proyecto
code .          # abre esta carpeta en VS Code
```

**b) Crea `main.py`** dentro de VS Code y escribe:

```python
print("¡Hola, GitHub!")
```

**c) Ejecútalo.** Pulsa el botón ▶ arriba a la derecha en VS Code, o en la terminal:

```bash
python3 main.py    # Linux
python main.py     # Windows
```

**d) Guarda una versión con Git**

```bash
git init
git add .
git commit -m "Primer commit"
```

**e) Súbelo a GitHub.** En GitHub, pulsa **New repository**, ponle un nombre (p. ej. `mi-proyecto`),
déjalo vacío y crea. Luego, en tu terminal:

```bash
git remote add origin https://github.com/TU-USUARIO/mi-proyecto.git
git branch -M main
git push -u origin main
```

<Pitfall>
Al hacer `git push`, GitHub te pedirá autenticarte, y **la contraseña normal ya no funciona**. La
forma más fácil es instalar **GitHub CLI** y ejecutar `gh auth login`:

- **Linux:** `sudo apt install gh` (o mira [cli.github.com](https://cli.github.com)).
- **Windows:** descárgalo de [cli.github.com](https://cli.github.com).

Ejecuta `gh auth login`, elige **HTTPS** y **autenticar en el navegador**. A partir de ahí, `git push`
funcionará sin pedirte nada. (Alternativa: crear un *Personal Access Token* en GitHub y usarlo como
contraseña.)
</Pitfall>

## Mini-ejercicios

<Collapsible title="1. ¿Cuál es la diferencia entre Git y GitHub?">

**Git** es el programa que, en tu ordenador, guarda el historial de versiones de tu código.
**GitHub** es la web donde subes ese código para guardarlo en la nube y enseñarlo. Git funciona sin
internet; GitHub es el lugar online donde publicas.

</Collapsible>

<Collapsible title="2. En Windows escribí python y no lo encuentra. ¿Qué pasó?">

Casi seguro no marcaste **"Add python.exe to PATH"** al instalar. Vuelve a ejecutar el instalador de
Python, elige **Modify** y activa esa casilla. Luego cierra y abre PowerShell otra vez.

</Collapsible>
