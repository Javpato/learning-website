# Configuration pour tes projets

<Accroche>« Avant ton premier projet, prépare ta machine une seule fois. Voici chaque étape. »</Accroche>

Les chapitres s'exécutent dans le navigateur, mais les **projets**, tu les écris sur ton propre
ordinateur et tu les publies sur **GitHub**. Ce guide t'y prépare — de façon **très guidée** — et tu ne
le fais qu'**une fois**. On installera trois choses : **Git**, **Python** et **VS Code** (l'éditeur).

> Choisis ton système dans les onglets ci-dessous (Linux ou Windows). Le reste des étapes est identique
> pour les deux.

## Qu'est-ce que GitHub ? (et Git)

Ce sont deux choses différentes utilisées ensemble :

- **Git** est un programme qui garde l'**historique** de ton code : chaque version, ce que tu as changé
  et quand. C'est comme une « sauvegarde » infinie qui te permet de revenir en arrière.
- **GitHub** est un **site web** où tu envoies ce code pour le garder dans le cloud, le partager et le
  montrer. C'est aussi ton **portfolio** : quand quelqu'un veut voir ce que tu sais faire, il regarde
  ton GitHub.

En résumé : tu programmes sur ton ordinateur → Git garde les versions → GitHub les publie en ligne.

## Étape 1 · Crée ton compte GitHub

C'est pareil sur n'importe quel système :

1. Va sur [github.com](https://github.com).
2. Clique sur **Sign up** (S'inscrire).
3. Saisis ton **e-mail**, un **mot de passe** et un **nom d'utilisateur** (il fera partie de l'adresse
   de tes projets, p. ex. `github.com/ton-utilisateur`).
4. Vérifie ton e-mail avec le code qu'on t'envoie.
5. C'est fait ! Tu as un compte. Garde bien ton identifiant et ton mot de passe.

## Étape 2 · Installe les outils

<Tabs>

<Tab label="🐧 Linux">

### 2.1 · Git

Ouvre un **terminal** et installe Git avec le gestionnaire de paquets de ton système :

```bash
sudo apt update
sudo apt install git        # Debian / Ubuntu / Mint
# Fedora :        sudo dnf install git
# Arch/Manjaro :  sudo pacman -S git
```

Vérifie qu'il est installé (il doit afficher un numéro de version) :

```bash
git --version
```

### 2.2 · Python

Presque toutes les distributions apportent déjà Python 3. Vérifie-le :

```bash
python3 --version
```

S'il n'apparaît pas, installe-le (avec `pip` et `venv`, que tu utiliseras dans les projets) :

```bash
sudo apt install python3 python3-pip python3-venv
```

> Sur Linux on utilise `python3` et `pip3` (pas `python` tout court).

### 2.3 · VS Code

Le plus rapide est avec snap :

```bash
sudo snap install code --classic
```

Tu n'utilises pas snap ? Télécharge le paquet **.deb** depuis
[code.visualstudio.com](https://code.visualstudio.com) et installe-le :

```bash
sudo dpkg -i ~/Téléchargements/code_*.deb
```

Ouvre-le en tapant `code` dans le terminal ou depuis le menu des applications.

</Tab>

<Tab label="🪟 Windows">

### 2.1 · Git

1. Va sur [git-scm.com/download/win](https://git-scm.com/download/win) ; le téléchargement démarre tout
   seul.
2. Lance l'installateur et clique sur **Next** à tous les écrans (les options par défaut conviennent).
   Il inclut une app appelée **Git Bash**, un terminal très pratique.
3. Ouvre **PowerShell** (cherche « PowerShell » dans le menu démarrer) et vérifie :

```powershell
git --version
```

### 2.2 · Python

1. Va sur [python.org/downloads](https://www.python.org/downloads) et clique sur le bouton jaune
   **Download Python 3.x**.
2. Lance l'installateur et — **très important** — coche en bas la case
   **« Add python.exe to PATH »** avant de continuer.
3. Clique sur **Install Now** et attends la fin.
4. Ouvre **PowerShell** et vérifie :

```powershell
python --version
```

> S'il dit qu'il ne trouve pas `python`, c'est que tu as oublié de cocher « Add to PATH » : relance
> l'installateur, choisis **Modify** et active cette case.

### 2.3 · VS Code

1. Va sur [code.visualstudio.com](https://code.visualstudio.com) et clique sur **Download for Windows**.
2. Lance l'installateur. Accepte l'accord et **coche « Add to PATH »** (et, si tu veux, « Ouvrir avec
   Code »).
3. Termine et ouvre **VS Code**.

</Tab>

</Tabs>

## Étape 3 · Présente à Git qui tu es

Git étiquette chaque sauvegarde avec ton nom et ton e-mail. Configure-le une fois (utilise le **même
e-mail** que sur GitHub). La même commande marche sur Linux et Windows :

```bash
git config --global user.name "Ton Nom"
git config --global user.email "ton-email@exemple.com"
```

## Étape 4 · Prépare VS Code pour Python

1. Ouvre VS Code.
2. Clique sur l'icône **Extensions** dans la barre latérale (ou `Ctrl+Shift+X`).
3. Cherche **Python** et installe celle de **Microsoft** (la première, avec des millions de
   téléchargements).
4. Avec ça, VS Code sait déjà exécuter et comprendre ton code Python (autocomplétion, bouton ▶ pour
   exécuter, avertissements d'erreurs…).

## Étape 5 · Ton premier flux complet

Créons un tout petit projet, exécutons-le et publions-le sur GitHub. C'est le flux que tu répéteras dans
**tous** les projets du cours.

**a) Crée le dossier et ouvre-le dans VS Code**

```bash
mkdir mi-proyecto
cd mi-proyecto
code .          # ouvre ce dossier dans VS Code
```

**b) Crée `main.py`** dans VS Code et écris :

```python
print("Bonjour, GitHub !")
```

**c) Exécute-le.** Clique sur le bouton ▶ en haut à droite dans VS Code, ou dans le terminal :

```bash
python3 main.py    # Linux
python main.py     # Windows
```

**d) Sauvegarde une version avec Git**

```bash
git init
git add .
git commit -m "Premier commit"
```

**e) Publie-le sur GitHub.** Sur GitHub, clique sur **New repository**, donne-lui un nom (p. ex.
`mi-proyecto`), laisse-le vide et crée. Puis, dans ton terminal :

```bash
git remote add origin https://github.com/TON-UTILISATEUR/mi-proyecto.git
git branch -M main
git push -u origin main
```

<Pitfall>
Au `git push`, GitHub te demandera de t'authentifier, et **le mot de passe normal ne marche plus**. Le
plus simple est d'installer **GitHub CLI** et de lancer `gh auth login` :

- **Linux :** `sudo apt install gh` (ou regarde [cli.github.com](https://cli.github.com)).
- **Windows :** télécharge-le sur [cli.github.com](https://cli.github.com).

Lance `gh auth login`, choisis **HTTPS** et **authentifier dans le navigateur**. À partir de là, `git
push` marchera sans rien te demander. (Alternative : créer un *Personal Access Token* sur GitHub et
l'utiliser comme mot de passe.)
</Pitfall>

## Mini-exercices

<Collapsible title="1. Quelle est la différence entre Git et GitHub ?">

**Git** est le programme qui, sur ton ordinateur, garde l'historique des versions de ton code.
**GitHub** est le site web où tu envoies ce code pour le garder dans le cloud et le montrer. Git marche
sans internet ; GitHub est l'endroit en ligne où tu publies.

</Collapsible>

<Collapsible title="2. Sur Windows j'ai tapé python et il ne le trouve pas. Que s'est-il passé ?">

Tu n'as presque sûrement pas coché **« Add python.exe to PATH »** à l'installation. Relance
l'installateur de Python, choisis **Modify** et active cette case. Puis ferme et rouvre PowerShell.

</Collapsible>
