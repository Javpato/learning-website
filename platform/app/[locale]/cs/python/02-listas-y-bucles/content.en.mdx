# Lists and Loops

<Accroche>« A variable holds one value. A list holds many — and a loop walks through them all. »</Accroche>

Until now each variable held **one** thing. But almost all programs handle *collections*: a shopping
list, a game's scores, your friends' names. That's what **lists** are for.

## Creating and indexing

A list is written between brackets `[]`, with the elements separated by commas:

```python
frutas = ["apple", "pear", "grape"]
print(frutas)          # ['apple', 'pear', 'grape']
print(len(frutas))     # 3  → how many elements there are
```

Each element has a **position** (index) that **starts at 0**:

```python
print(frutas[0])   # apple  (the first)
print(frutas[1])   # pear
print(frutas[-1])  # grape  (the last; negatives count from the end)
```

<Pitfall>
If you ask for an index that doesn't exist (`frutas[3]` when there are only 3 elements, indices 0, 1
and 2), Python raises an `IndexError`. Remember: the last index is always `len(lista) - 1`.
</Pitfall>

## Modifying a list

Lists are **mutable**: you can change them after creating them.

```python
numeros = [10, 20, 30]
numeros.append(40)     # add to the end      → [10, 20, 30, 40]
numeros[0] = 99        # change by index     → [99, 20, 30, 40]
numeros.pop()          # remove the last     → [99, 20, 30]
numeros.remove(20)     # remove that value   → [99, 30]
print(numeros)
```

## Slices (slicing)

`lista[start:end]` gives you a chunk, **not including** the `end` index:

```python
letras = ["a", "b", "c", "d", "e"]
print(letras[1:3])   # ['b', 'c']
print(letras[:2])    # ['a', 'b']   (from the start)
print(letras[2:])    # ['c', 'd', 'e']  (to the end)
```

## The `for` loop

A `for` walks through the elements of a list, **one by one**:

```python
for color in ["red", "green", "blue"]:
    print(color)
```

## `range()` — looping over numbers

`range(start, end)` generates the numbers from `start` to `end - 1` (the end is **not** included):

```python
for n in range(1, 5):
    print(n)      # 1, 2, 3, 4  (it doesn't reach 5!)
```

## Handy methods

```python
nums = [3, 1, 2]
nums.append(0)     # [3, 1, 2, 0]
nums.sort()        # [0, 1, 2, 3]  (sorts in place)
print(sum(nums))   # 6
print(max(nums))   # 3
print(2 in nums)   # True  (is 2 in the list?)
```

{/* sol:

<Pitfall>
`range(1, 11)` reaches **10**, not 11: the end is excluded. It's the most common "off-by-one" error.
When in doubt, print it with a `for` and check.
</Pitfall>
