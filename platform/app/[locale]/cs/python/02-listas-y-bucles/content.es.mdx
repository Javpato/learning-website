# Listas y bucles

<Accroche>« Una variable guarda un valor. Una lista guarda muchos — y un bucle los recorre todos. »</Accroche>

Hasta ahora cada variable guardaba **una** cosa. Pero casi todos los programas manejan *colecciones*:
una lista de la compra, las puntuaciones de una partida, los nombres de tus amigos. Para eso están
las **listas**.

## Crear e indexar

Una lista se escribe entre corchetes `[]`, con los elementos separados por comas:

```python
frutas = ["manzana", "pera", "uva"]
print(frutas)          # ['manzana', 'pera', 'uva']
print(len(frutas))     # 3  → cuántos elementos hay
```

Cada elemento tiene una **posición** (índice) que **empieza en 0**:

```python
print(frutas[0])   # manzana  (el primero)
print(frutas[1])   # pera
print(frutas[-1])  # uva      (el último; los negativos cuentan desde el final)
```

{/* sol:
frutas = ["manzana", "pera", "uva"]
print(len(frutas))
*/}

Si pides un índice que no existe (`frutas[3]` cuando solo hay 3 elementos, índices 0, 1 y 2), Python
lanza un `IndexError`. Recuerda: el último índice es siempre `len(lista) - 1`.
</Pitfall>

## Modificar una lista

Las listas son **mutables**: puedes cambiarlas después de crearlas.

```python
numeros = [10, 20, 30]
numeros.append(40)     # añade al final     → [10, 20, 30, 40]
numeros[0] = 99        # cambia por índice   → [99, 20, 30, 40]
numeros.pop()          # quita el último     → [99, 20, 30]
numeros.remove(20)     # quita ese valor     → [99, 30]
print(numeros)
```

## Rebanadas (slicing)

`lista[inicio:fin]` te da un trozo, **sin incluir** el índice `fin`:

```python
letras = ["a", "b", "c", "d", "e"]
print(letras[1:3])   # ['b', 'c']
print(letras[:2])    # ['a', 'b']   (desde el principio)
print(letras[2:])    # ['c', 'd', 'e']  (hasta el final)
```

## El bucle `for`

Un `for` recorre los elementos de una lista, **uno por uno**:

```python
for color in ["rojo", "verde", "azul"]:
    print(color)
```

## `range()` — recorrer números

`range(inicio, fin)` genera los números desde `inicio` hasta `fin - 1` (el final **no** se incluye):

```python
for n in range(1, 5):
    print(n)      # 1, 2, 3, 4  (¡no llega al 5!)
```

## Métodos útiles

```python
nums = [3, 1, 2]
nums.append(0)     # [3, 1, 2, 0]
nums.sort()        # [0, 1, 2, 3]  (ordena en el sitio)
print(sum(nums))   # 6
print(max(nums))   # 3
print(2 in nums)   # True  (¿está el 2 en la lista?)
```

{/* sol:
nums = [3, 1, 2]
nums.append(0)
nums.sort()
print(nums)
*/}
<PyExercise
  task="Parte de [3, 1, 2], añade un 0, ordena la lista y muéstrala."
  starter={`nums = [3, 1, 2]
# añade 0, ordena, imprime
print()`}
  expected_output="[0, 1, 2, 3]"
  hint={`nums.append(0), luego nums.sort(), luego print(nums).`}
/>

<Pitfall>
`range(1, 11)` llega hasta el **10**, no hasta el 11: el final se excluye. Es el error de "uno de
más / uno de menos" más común. Cuando dudes, imprímelo con un `for` y compruébalo.
</Pitfall>
