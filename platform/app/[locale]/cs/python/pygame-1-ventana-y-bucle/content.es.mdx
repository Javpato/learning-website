# Ventana y bucle de juego (Pygame)

<Accroche>« Todo videojuego, por dentro, es el mismo bucle repetido 60 veces por segundo. »</Accroche>

Empezamos los videojuegos con **Pygame**, la librería más popular para hacer juegos 2D en Python.
Pygame necesita una **ventana**, así que se ejecuta en tu ordenador, no en el navegador — pero la
*lógica* que aprenderás aquí sí la puedes practicar en las cajas de código.

## El esqueleto de todo juego

Cada juego de Pygame tiene la misma estructura. Apréndela y la reutilizarás siempre:

```python
import pygame

pygame.init()
pantalla = pygame.display.set_mode((600, 400))   # ventana de 600x400
reloj = pygame.time.Clock()

corriendo = True
while corriendo:
    for evento in pygame.event.get():          # 1) EVENTOS
        if evento.type == pygame.QUIT:
            corriendo = False

    # 2) ACTUALIZAR el estado del juego

    pantalla.fill((0, 0, 0))                    # 3) DIBUJAR (fondo negro…)
    pygame.display.flip()                       #    …y mostrar el fotograma

    reloj.tick(60)                              # 4) 60 fotogramas por segundo

pygame.quit()
```

Ese bucle `while` es el **bucle de juego** (*game loop*). En cada vuelta (un *fotograma*) hace siempre
lo mismo: **eventos → actualizar → dibujar**, y `reloj.tick(60)` lo mantiene a 60 fotogramas por
segundo.

## Practica la lógica del bucle

<Pitfall>
Si olvidas atender los eventos (`for evento in pygame.event.get()`), la ventana se **congela** y el
sistema la marca como "no responde". Procesar los eventos en cada fotograma no es opcional: es lo que
mantiene la ventana viva.
</Pitfall>

## Mini-ejercicios

<Collapsible title="1. ¿Qué hace reloj.tick(60)?">

Limita el juego a **60 fotogramas por segundo**: pausa lo justo para no ir más rápido. Sin él, el
juego correría tan deprisa como pueda el ordenador, distinto en cada máquina. Controla la velocidad
con `tick`, nunca con `sleep`.

</Collapsible>

<Collapsible title="2. ¿Por qué pygame.display.flip() va al final?">

Porque dibujas todo el fotograma "entre bastidores" y `flip()` lo muestra de golpe. Así se evita el
parpadeo: el jugador solo ve fotogramas completos, nunca a medio dibujar.

</Collapsible>
