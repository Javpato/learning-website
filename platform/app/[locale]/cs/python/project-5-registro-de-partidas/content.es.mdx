# Proyecto 5 — Registro de partidas

<Accroche>« El historial de tu juego: apunta cada partida y descubre tus estadísticas — victorias, mejor puntuación, enemigos derrotados. »</Accroche>

Quinto proyecto para tu GitHub, y el primero que **guarda datos en disco**. Reúne todo el Módulo 3:
diccionarios, manejo de errores, archivos, JSON y algún módulo estándar. Se escribe en tu máquina.

## Qué vas a construir

Una app de terminal que registra las partidas de un juego y muestra tus estadísticas, con guardado en
JSON.

```text
==== REGISTRO DE PARTIDAS ====
1) Añadir partida  2) Ver estadísticas  3) Salir
Elige: 1
Personaje: Guerrero
Resultado (victoria/derrota): victoria
Puntos: 1200
Enemigos derrotados: 8
Guardada.

Elige: 2
Partidas jugadas ... 12
Victorias .......... 8 (67%)
Mejor puntuación ... 1800
Enemigos totales ... 74
```

## Lo que necesitas saber

```text
diccionarios y listas    funciones           int()/float() para números
try/except (validación)  json.dump / json.load   f-strings y porcentajes
```

## Modelo de datos

Cada partida es un diccionario; todas van en una lista que guardas en un archivo JSON:

```python
partidas = [
    {"personaje": "Guerrero", "resultado": "victoria", "puntos": 1200, "enemigos": 8},
    {"personaje": "Maga",     "resultado": "derrota",  "puntos": 640,  "enemigos": 3},
]
```

## Pasos guiados

```text
1. Al arrancar, carga las partidas desde partidas.json (si el archivo no existe, empieza con []).
   Pista: envuelve el json.load en un try/except FileNotFoundError.
2. Funciones:
     - añadir(partidas): pide personaje, resultado, puntos (int, valida con try/except) y enemigos.
     - estadisticas(partidas): calcula partidas jugadas, victorias y su porcentaje, la mejor
       puntuación (max) y el total de enemigos (suma).
     - guardar(partidas): vuelca la lista a partidas.json con json.dump.
3. Menú con while: añadir / ver estadísticas / salir. Guarda al salir (o tras cada cambio).
4. Formatea el porcentaje sin decimales: f"{victorias / total * 100:.0f}%".
```

<Pitfall>
`input()` da texto: convierte los puntos con `int(...)` **dentro de un try/except** para que una
entrada como "mil" no rompa el programa. Y recuerda cargar con `try/except FileNotFoundError` la
primera vez, cuando el archivo aún no existe.
</Pitfall>
