# Decoradores

<Accroche>« Añade comportamiento a una función sin tocar su código. Envuélvela — como un golpe crítico que duplica el daño. »</Accroche>

En Python las **funciones son objetos**: puedes guardarlas en variables, pasarlas como argumento y
devolverlas. Sobre esa idea se construyen los **decoradores**, una forma elegante de envolver una
función con comportamiento extra (registro, validación, un multiplicador de daño…).

## Funciones que reciben funciones

```python
def aplicar(func, valor):
    return func(valor)

def critico(x):
    return x * 2

print(aplicar(critico, 5))   # 10  → pasamos la función critico como argumento
```

## Un decorador

Un **decorador** es una función que recibe una función y devuelve otra que la envuelve. Con `@nombre`
encima de una función, Python la sustituye por la versión envuelta. Por ejemplo, convertir un grito de
guerra en mayúsculas:

```python
def mayusculas(func):
    def envoltura():
        return func().upper()      # llama a la original y transforma el resultado
    return envoltura

@mayusculas
def grito():
    return "cargad"

print(grito())   # CARGAD
```

`@mayusculas` equivale a `grito = mayusculas(grito)`.

## Decorar funciones con argumentos

Para envolver funciones que reciben argumentos, la envoltura usa `*args` y `**kwargs`. Un golpe crítico
que duplica el daño calculado:

```python
def golpe_critico(func):
    def envoltura(*args, **kwargs):
        return func(*args, **kwargs) * 2
    return envoltura

@golpe_critico
def daño(a, b):
    return a + b

print(daño(3, 4))   # 14  → (3 + 4) * 2
```

<Pitfall>
Al envolver una función pierdes su nombre y su docstring (pasan a ser los de `envoltura`). Para
conservarlos, decora la envoltura con `@functools.wraps(func)`. Es una buena costumbre en decoradores
serios.
</Pitfall>

## Mini-ejercicios

<Collapsible title="1. ¿Qué hace @algo encima de una función?">

Sustituye la función por `algo(funcion)`. Es azúcar sintáctico: `@log` antes de `def f()` equivale a
escribir `f = log(f)` después.

</Collapsible>

<Collapsible title="2. Un decorador que registre cada llamada (útil para depurar el combate).">

```python
def registrar(func):
    def envoltura(*args):
        print(f"llamando a {func.__name__}{args}")
        return func(*args)
    return envoltura

@registrar
def daño(a, b):
    return a + b

daño(2, 3)   # imprime: llamando a daño(2, 3)
```

</Collapsible>
