# Decorators

<Accroche>« Add behavior to a function without touching its code. Wrap it — like a critical hit that doubles the damage. »</Accroche>

In Python, **functions are objects**: you can store them in variables, pass them as arguments and
return them. On that idea the **decorators** are built, an elegant way to wrap a function with extra
behavior (logging, validation, a damage multiplier…).

## Functions that take functions

```python
def aplicar(func, valor):
    return func(valor)

def critico(x):
    return x * 2

print(aplicar(critico, 5))   # 10  → we pass the critico function as an argument
```

## A decorator

A **decorator** is a function that takes a function and returns another that wraps it. With `@name`
above a function, Python replaces it with the wrapped version. For example, turning a battle cry into
uppercase:

```python
def mayusculas(func):
    def envoltura():
        return func().upper()      # calls the original and transforms the result
    return envoltura

@mayusculas
def grito():
    return "cargad"

print(grito())   # CARGAD
```

`@mayusculas` is equivalent to `grito = mayusculas(grito)`.

## Decorating functions with arguments

To wrap functions that take arguments, the wrapper uses `*args` and `**kwargs`. A critical hit that
doubles the computed damage:

```python
def golpe_critico(func):
    def envoltura(*args, **kwargs):
        return func(*args, **kwargs) * 2
    return envoltura

@golpe_critico
def daño(a, b):
    return a + b

print(daño(3, 4))   # 14  → (3 + 4) * 2
```

<Pitfall>
When you wrap a function you lose its name and its docstring (they become `envoltura`'s). To keep them,
decorate the wrapper with `@functools.wraps(func)`. It's a good habit in serious decorators.
</Pitfall>

## Mini-exercises

<Collapsible title="1. What does @something above a function do?">

It replaces the function with `something(function)`. It's syntactic sugar: `@log` before `def f()` is
equivalent to writing `f = log(f)` afterwards.

</Collapsible>

<Collapsible title="2. A decorator that logs every call (handy for debugging combat).">

```python
def registrar(func):
    def envoltura(*args):
        print(f"calling {func.__name__}{args}")
        return func(*args)
    return envoltura

@registrar
def daño(a, b):
    return a + b

daño(2, 3)   # prints: calling daño(2, 3)
```

</Collapsible>
