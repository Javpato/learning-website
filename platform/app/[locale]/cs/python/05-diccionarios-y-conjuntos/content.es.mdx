# Diccionarios y conjuntos

<Accroche>« Las listas guardan cosas en fila. Los diccionarios las guardan con etiqueta. »</Accroche>

Una **lista** encuentra sus elementos por posición (`lista[0]`). Un **diccionario** los encuentra por
un **nombre** (una *clave*). Es la estructura de datos más usada de Python.

## Diccionarios

Un diccionario asocia **claves** con **valores**, entre llaves `{}`:

```python
persona = {"nombre": "Ada", "edad": 36}
print(persona["nombre"])   # Ada
persona["edad"] = 37       # cambiar un valor
persona["ciudad"] = "Londres"   # añadir una clave nueva
print(persona)
```

## `get` — acceso seguro

Si pides una clave que no existe con corchetes, obtienes un `KeyError`. `get` devuelve `None` (o un
valor por defecto) en su lugar:

```python
print(persona.get("telefono"))          # None
print(persona.get("telefono", "N/D"))   # N/D
```

<Pitfall>
`persona["telefono"]` con una clave inexistente **rompe** el programa (`KeyError`). Cuando no estés
seguro de que la clave exista, usa `persona.get("telefono")`.
</Pitfall>

## Recorrer un diccionario

`.items()` te da las parejas clave-valor para un `for`:

```python
inventario = {"manzanas": 3, "peras": 5}
for producto, cantidad in inventario.items():
    print(producto, "->", cantidad)
```

## Contar con diccionarios

Un patrón clásico: contar cuántas veces aparece cada cosa.

```python
letras = "banana"
conteo = {}
for letra in letras:
    conteo[letra] = conteo.get(letra, 0) + 1
print(conteo)   # {'b': 1, 'a': 3, 'n': 2}
```

## Conjuntos (`set`)

Un **conjunto** es una colección **sin orden y sin duplicados**. Perfecto para quitar repetidos o
comprobar pertenencia rápido:

```python
numeros = [1, 2, 2, 3, 3, 3]
unicos = set(numeros)      # {1, 2, 3}
print(len(unicos))         # 3

vocales = {"a", "e", "i", "o", "u"}
print("e" in vocales)      # True
```

## Mini-ejercicios

<Collapsible title="1. ¿Cómo obtener solo las claves de un diccionario?">

Con `.keys()` (o recorriendo el diccionario directamente):

```python
d = {"a": 1, "b": 2}
print(list(d.keys()))   # ['a', 'b']
for clave in d:
    print(clave)        # a, b
```

</Collapsible>

<Collapsible title="2. ¿Qué imprime {1, 2, 2, 3}?">

`{1, 2, 3}` — un conjunto elimina los duplicados automáticamente.

</Collapsible>
