# Diccionarios y conjuntos

<Accroche>« Las listas guardan cosas en fila. Los diccionarios las guardan con etiqueta — como la ficha de un personaje. »</Accroche>

Una **lista** encuentra sus elementos por posición (`lista[0]`). Un **diccionario** los encuentra por
un **nombre** (una *clave*). Es la estructura de datos más usada de Python, y la forma natural de
guardar la ficha de un personaje, un objeto o un enemigo en un juego.

## Diccionarios

Un diccionario asocia **claves** con **valores**, entre llaves `{}`. Es perfecto para la ficha de un
héroe:

```python
heroe = {"nombre": "Link", "hp": 100, "nivel": 5}
print(heroe["nombre"])     # Link
heroe["hp"] = 80           # cambiar un valor (recibió daño)
heroe["mana"] = 30         # añadir una clave nueva
print(heroe)
```

## `get` — acceso seguro

Si pides una clave que no existe con corchetes, obtienes un `KeyError`. `get` devuelve `None` (o un
valor por defecto) en su lugar — útil cuando no sabes si el héroe tiene esa estadística:

```python
print(heroe.get("escudo"))          # None
print(heroe.get("escudo", 0))       # 0
```

<Pitfall>
`heroe["escudo"]` con una clave inexistente **rompe** el programa (`KeyError`). Cuando no estés seguro
de que la clave exista, usa `heroe.get("escudo", 0)` con un valor por defecto.
</Pitfall>

## Recorrer un diccionario

`.items()` te da las parejas clave-valor para un `for`. Ideal para mostrar todas las estadísticas:

```python
stats = {"atk": 8, "def": 7, "vel": 9}
for nombre, valor in stats.items():
    print(nombre, "->", valor)
```

## Contar con diccionarios

Un patrón clásico: contar cuántas veces aparece cada cosa. Por ejemplo, qué botín soltó una horda de
enemigos:

```python
botin = ["oro", "poción", "oro", "oro", "poción"]
conteo = {}
for objeto in botin:
    conteo[objeto] = conteo.get(objeto, 0) + 1
print(conteo)   # {'oro': 3, 'poción': 2}
```

## Conjuntos (`set`)

Un **conjunto** es una colección **sin orden y sin duplicados**. Perfecto para saber qué tipos de
enemigo distintos aparecen en una oleada, o para comprobar pertenencia rápido:

```python
oleada = ["fuego", "agua", "fuego", "planta", "agua", "fuego"]
tipos = set(oleada)        # {'fuego', 'agua', 'planta'}
print(len(tipos))          # 3

resistencias = {"fuego", "hielo"}
print("fuego" in resistencias)   # True
```

## Mini-ejercicios

<Collapsible title="1. ¿Cómo obtener solo las claves de un diccionario?">

Con `.keys()` (o recorriendo el diccionario directamente):

```python
d = {"atk": 8, "def": 7}
print(list(d.keys()))   # ['atk', 'def']
for clave in d:
    print(clave)        # atk, def
```

</Collapsible>

<Collapsible title="2. ¿Qué imprime {1, 2, 2, 3}?">

`{1, 2, 3}` — un conjunto elimina los duplicados automáticamente.

</Collapsible>
