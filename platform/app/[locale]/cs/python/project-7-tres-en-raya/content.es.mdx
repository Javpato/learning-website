# Proyecto 7 — Tres en raya

<Accroche>« Un tablero, dos jugadores, tres en línea. Sencillo de jugar, delicioso de programar. »</Accroche>

Séptimo proyecto para tu GitHub. El *tres en raya* (tic-tac-toe) te hace pensar en **tableros,
turnos y condiciones de victoria** — y es el escalón perfecto antes de los juegos con gráficos.
Se escribe en tu máquina.

## Qué vas a construir

```text
 1 | 2 | 3        X | O | X
-----------      -----------
 4 | 5 | 6   →    O | X |
-----------      -----------
 7 | 8 | 9          |   | O

Turno de X. ¿Casilla? 5
¡X gana!
```

## Lo que necesitas saber

```text
listas (el tablero)     bucles           if / elif / else
funciones o clases      turnos            comprobar filas/columnas/diagonales
```

## El modelo del tablero

Representa el tablero como una lista de 9 posiciones (o una lista de listas 3×3). Empieza con números
para que el jugador sepa qué casilla elegir:

```python
tablero = [" "] * 9      # 9 casillas vacías
# posiciones:  0 1 2 / 3 4 5 / 6 7 8
```

## Pasos guiados

```text
1. Función dibujar(tablero): imprime la cuadrícula 3×3 con las marcas y las líneas separadoras.
2. Bucle de turnos que alterna entre "X" y "O":
     - pide la casilla, valida que esté libre y dentro de rango
     - coloca la marca del jugador actual
3. Función hay_ganador(tablero): comprueba las 8 líneas posibles (3 filas, 3 columnas, 2 diagonales).
   Pista: guarda las líneas como listas de índices y recórrelas.
4. Tras cada jugada: si hay ganador, anúncialo y termina; si el tablero está lleno, es empate.
5. Cambia de jugador y repite.
```

<Pitfall>
Las 8 líneas ganadoras se escriben una sola vez como datos, no con 8 `if` gigantes:
`lineas = [[0,1,2],[3,4,5],[6,7,8],[0,3,6],[1,4,7],[2,5,8],[0,4,8],[2,4,6]]`. Recórrelas y comprueba si
las tres casillas de una línea tienen la misma marca (y no están vacías).
</Pitfall>

## Mejoras para GitHub

```text
- Modo 1 jugador contra una IA sencilla (elige casilla libre al azar…).
- IA que bloquea y gana cuando puede.
- Marcador entre partidas.
- Tablero más bonito con colores.
- Opción de volver a jugar.
```
