# Project 7 — Tic-Tac-Toe

<Accroche>« A board, two players, three in a row. Simple to play, delightful to program. »</Accroche>

Seventh project for your GitHub. *Tic-tac-toe* makes you think about **boards, turns and win

## What you'll build

```text
 1 | 2 | 3        X | O | X
-----------      -----------
 4 | 5 | 6   →    O | X |
-----------      -----------
 7 | 8 | 9          |   | O

X's turn. Square? 5
X wins!
```

## What you need to know

```text
lists (the board)      loops            if / elif / else
functions or classes   turns            check rows/columns/diagonals
```

## The board model

Represent the board as a list of 9 positions (or a 3×3 list of lists). Start with numbers so the player
knows which square to choose:

```python
tablero = [" "] * 9      # 9 empty squares
# positions:  0 1 2 / 3 4 5 / 6 7 8
```

## Guided steps

```text
1. dibujar(tablero) function: print the 3×3 grid with the marks and the separator lines.
2. Turn loop that alternates between "X" and "O":
     - ask for the square, validate it's free and in range
     - place the current player's mark
3. hay_ganador(tablero) function: check the 8 possible lines (3 rows, 3 columns, 2 diagonals).
   Hint: store the lines as lists of indices and loop over them.
4. After each move: if there's a winner, announce it and end; if the board is full, it's a draw.
5. Switch players and repeat.
```

<Pitfall>
The 8 winning lines are written once as data, not with 8 giant `if`s:
`lineas = [[0,1,2],[3,4,5],[6,7,8],[0,3,6],[1,4,7],[2,5,8],[0,4,8],[2,4,6]]`. Loop over them and check
whether the three squares of a line have the same mark (and aren't empty).
</Pitfall>
