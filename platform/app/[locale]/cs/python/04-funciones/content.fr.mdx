# Fonctions

<Accroche>« Écris une fois, utilise mille fois. Une fonction est une idée avec un nom. »</Accroche>

Une **fonction** est un bloc de code nommé que tu peux exécuter quand tu veux. Elle évite de répéter,
organise le programme et rend chaque pièce testable séparément.

## Définir et appeler

On la définit avec `def`, et ce que la fonction **renvoie** s'indique avec `return` :

```python
def saludar(nombre):
    return "Bonjour, " + nombre

mensaje = saludar("Ada")   # on appelle la fonction
print(mensaje)             # Bonjour, Ada
```

`nombre` est un **paramètre** (l'emplacement) ; `"Ada"` est l'**argument** (la vraie valeur que tu
passes).

## `return` n'est pas `print`

`print` **affiche** quelque chose ; `return` **rend** une valeur à celui qui a appelé la fonction, pour
continuer à l'utiliser. Une fonction sans `return` renvoie `None`.

```python
def area(base, altura):
    return base * altura

print(area(4, 3))          # 12
print(area(4, 3) * 2)      # 24  → le résultat peut continuer à être utilisé
```

## Arguments par défaut

Un paramètre peut avoir une valeur par défaut, utilisée si tu ne passes pas cet argument :

```python
def saludar(nombre, saludo="Bonjour"):
    return saludo + ", " + nombre

print(saludar("Ana"))            # Bonjour, Ana
print(saludar("Ana", "Salut"))   # Salut, Ana
```

## Portée (scope)

Les variables créées **à l'intérieur** d'une fonction n'existent que là. Elles ne sont pas visibles de
l'extérieur :

```python
def f():
    x = 10      # locale à f
    return x

print(f())      # 10
# print(x)      # NameError ! x n'existe pas ici dehors
```

<Pitfall>
Une fonction qui fait un calcul devrait le **renvoyer** avec `return`, pas seulement l'afficher. Si tu
ne fais qu'un `print` à l'intérieur, tu ne peux pas réutiliser le résultat — et `variable =
ma_fonction()` te donnera `None`.
</Pitfall>

## Beaucoup d'arguments : `*args` et `**kwargs`

Parfois tu ne sais pas combien d'arguments vont arriver. `*args` les recueille dans un tuple :

```python
def suma_todos(*numeros):
    return sum(numeros)

print(suma_todos(1, 2, 3, 4))   # 10
```

## Documenter : docstrings

La première ligne de texte à l'intérieur d'une fonction est sa **docstring**, une description de ce
qu'elle fait :

```python
def area(base, altura):
    """Renvoie l'aire d'un rectangle."""
    return base * altura
```

<Collapsible title="2. Fonction es_primo(n) qui dit si un nombre est premier.">

```python
def es_primo(n):
    if n < 2:
        return False
    for d in range(2, n):
        if n % d == 0:
            return False
    return True

print(es_primo(7))   # True
print(es_primo(8))   # False
```
