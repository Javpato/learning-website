## The key idea: each character is a dictionary

Store each character as a **dictionary** with its name, its class and a nested **stats**
dictionary. All the characters go together in a **list**. That way you can add or rebalance heroes
without touching the menu logic:

```python
personajes = [
    {"nombre": "Warrior", "clase": "Tank",      "stats": {"hp": 120, "atk": 15, "def": 12, "vel": 5}},
    {"nombre": "Mage",    "clase": "Sorcerer",  "stats": {"hp": 70,  "atk": 25, "def": 6,  "vel": 9}},
    {"nombre": "Rogue",   "clase": "Assassin",  "stats": {"hp": 85,  "atk": 18, "def": 8,  "vel": 14}},
]
```

Notice the shape: a **list** of **dictionaries**, and inside each one, another **dictionary**
(`stats`). It's exactly how a real game stores its characters.

## Guided steps

```text
1. Create the `personajes` list with at least 3 dictionaries (nombre, clase, stats).
2. Show the menu by looping over the list with enumerate (starting at 1):
     - for each character, print its number, name, class and stats.
     - read the stats with personaje["stats"]["hp"], etc.
3. Ask for the choice with input() and convert it to an integer.
4. Validate that the number is between 1 and len(personajes); if not, ask again.
5. Grab the chosen one with personajes[eleccion - 1] (the user counts from 1, the list from 0).
6. Print a summary of the chosen character and a "To battle!" message.
```

<Pitfall>
The user picks number **1**, but the list starts at index **0**. Subtract 1 before indexing:
`personajes[eleccion - 1]`. And before indexing, **validate**: if the number isn't between `1` and
`len(personajes)`, ask again instead of blowing up with an `IndexError`.
</Pitfall>
