# Project 2 — Rock, Paper, Scissors

<Accroche>« You against the machine. Best of several rounds. And you write it all yourself. »</Accroche>

Second project for your GitHub. As always: the guide is here, but you write the code **on your own

## What you'll build

A terminal game where you choose rock, paper or scissors against the computer, with a **scoreboard**
that keeps count.

```text
Rock, paper, scissors. Best of 3!

Your move (rock/paper/scissors): rock
The machine chose scissors.
You win this round!   → You 1 - 0 Machine

Your move (rock/paper/scissors): paper
The machine chose scissors.
You lose this round.  → You 1 - 1 Machine
```

## Guided steps

Build it in parts and run it after each step. The recipe (in words, not in code):

```text
1. Import random and define the list ["rock", "paper", "scissors"].
2. Write a function ganador(jugador, maquina) that returns:
     - "empate" if they're equal
     - "jugador" if the player wins
     - "maquina" otherwise
   (Rock beats scissors; scissors beats paper; paper beats rock.)
3. Keep two counters: puntos_jugador and puntos_maquina, starting at 0.
4. Repeat the rounds with a loop:
     - ask the player for their move and validate it's a valid option
     - the machine chooses with random.choice
     - use your function ganador(...) to decide and add to the score
     - show the scoreboard after each round
5. Finish when someone reaches the needed points and announce the champion.
```

<Pitfall>
The logic of who wins is the heart of the game: isolate it in its own **function** `ganador(...)`. That
way you can test it alone (for example, `print(ganador("rock", "scissors"))` should give `"jugador"`)
without playing a whole match.
</Pitfall>
