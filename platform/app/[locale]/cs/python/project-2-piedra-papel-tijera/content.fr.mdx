# Projet 2 — Pierre, papier, ciseaux

<Accroche>« Toi contre la machine. Au meilleur de plusieurs manches. Et tu écris tout toi-même. »</Accroche>

Deuxième projet pour ton GitHub. Comme toujours : le guide est ici, mais tu écris le code **sur ta
propre machine** et tu le publies sur ton profil. Tu utiliseras ce qui est dans le **Module 1** :
`input`, `if/elif/else`, les boucles, `random` et — la nouveauté — les **fonctions** pour organiser le
jeu.

## Ce que tu vas construire

Un jeu de terminal où tu choisis pierre, papier ou ciseaux contre l'ordinateur, avec un **tableau des
scores** qui tient le compte.

```text
Pierre, papier, ciseaux. Au meilleur de 3 !

Ton coup (pierre/papier/ciseaux) : pierre
La machine a choisi ciseaux.
Tu gagnes cette manche !   → Toi 1 - 0 Machine

Ton coup (pierre/papier/ciseaux) : papier
La machine a choisi ciseaux.
Tu perds cette manche.     → Toi 1 - 1 Machine
```

## Ce que tu dois savoir

```text
input()          random.choice()      fonctions (def / return)
if / elif / else  boucles while/for     compteurs (score)
```

## Un rappel interactif

`random.choice(lista)` choisit un élément au hasard. Exécute ceci plusieurs fois :

<PyExercise
  task="Observe comment random.choice choisit le coup de la machine. (Bac à sable — pas le rendu.)"
  starter={`import random
opciones = ["pierre", "papier", "ciseaux"]
print("La machine a choisi :", random.choice(opciones))`}
/>

## Étapes guidées

Construis-le par parties et exécute-le après chaque étape. La recette (en mots, pas en code) :

```text
1. Importe random et définis la liste ["pierre", "papier", "ciseaux"].
2. Écris une fonction ganador(jugador, maquina) qui renvoie :
     - "empate" s'ils sont égaux
     - "jugador" si le joueur gagne
     - "maquina" sinon
   (Pierre bat ciseaux ; ciseaux bat papier ; papier bat pierre.)
3. Tiens deux compteurs : puntos_jugador et puntos_maquina, en partant de 0.
4. Répète les manches avec une boucle :
     - demande le coup au joueur et valide que c'est une option correcte
     - la machine choisit avec random.choice
     - utilise ta fonction ganador(...) pour décider et ajoute au score
     - affiche le score après chaque manche
5. Termine quand quelqu'un atteint les points nécessaires et annonce le champion.
```

<Pitfall>
La logique de qui gagne est le cœur du jeu : isole-la dans sa propre **fonction** `ganador(...)`. Ainsi
tu peux la tester seule (par exemple, `print(ganador("pierre", "ciseaux"))` devrait donner
`"jugador"`) sans jouer une partie entière.
</Pitfall>
