# Strings

<Accroche>« Text is data. And Python has sharp tools to slice it, measure it and transform it. »</Accroche>

A **string** is a sequence of characters. On the inside it behaves like a list of letters: you can index
it, slice it and measure its length.

```python
saludo = "Python"
print(len(saludo))   # 6
print(saludo[0])     # P
print(saludo[-1])    # n
print(saludo[0:3])   # Pyt   (a slice, like on lists)
```

## f-strings — modern formatting

An **f-string** starts with `f` and puts variables between braces. It's the cleanest way to build text:

```python
nombre = "Ada"
edad = 36
print(f"{nombre} is {edad} years old")   # Ada is 36 years old
```

## String methods

Strings come with many methods. None changes the original string (they're **immutable**): they all
**return a new one**.

```python
texto = "  Hello World  "
print(texto.upper())        # "  HELLO WORLD  "
print(texto.lower())        # "  hello world  "
print(texto.strip())        # "Hello World"   (removes spaces at the ends)
print(texto.replace("o", "0"))  # "  Hell0 W0rld  "
```

<Pitfall>
String methods **don't modify** the variable: `texto.upper()` doesn't change `texto`, it returns a new
string. If you want to keep it, reassign: `texto = texto.upper()`.
</Pitfall>

## `split` and `join` — from text to list and back

`split()` splits a string into a list; `join()` joins a list into a string:

```python
frase = "one two three"
palabras = frase.split()        # ['one', 'two', 'three']
print(len(palabras))            # 3

partes = ["2024", "07", "05"]
print("-".join(partes))         # 2024-07-05
```

## Searching and replacing

```python
correo = "ana@example.com"
print(correo.startswith("ana"))   # True
print("@" in correo)              # True
print(correo.find("@"))           # 3   (position of the @)
print(correo.replace(".com", ".es"))  # ana@example.es
```
