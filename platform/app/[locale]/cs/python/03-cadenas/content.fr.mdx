# Chaînes de caractères

<Accroche>« Le texte, c'est des données. Et Python a des outils affûtés pour le couper, le mesurer et le transformer. »</Accroche>

Une **chaîne** (*string*) est une séquence de caractères. À l'intérieur, elle se comporte comme une
liste de lettres : tu peux l'indexer, la trancher et mesurer sa longueur.

```python
saludo = "Python"
print(len(saludo))   # 6
print(saludo[0])     # P
print(saludo[-1])    # n
print(saludo[0:3])   # Pyt   (une tranche, comme dans les listes)
```

## f-strings — le formatage moderne

Une **f-string** commence par `f` et met des variables entre accolades. C'est la façon la plus propre de
construire du texte :

```python
nombre = "Ada"
edad = 36
print(f"{nombre} a {edad} ans")   # Ada a 36 ans
```

## Méthodes de texte

Les chaînes apportent beaucoup de méthodes. Aucune ne change la chaîne d'origine (elles sont
**immuables**) : toutes **renvoient une nouvelle**.

```python
texto = "  Bonjour Monde  "
print(texto.upper())        # "  BONJOUR MONDE  "
print(texto.lower())        # "  bonjour monde  "
print(texto.strip())        # "Bonjour Monde"   (retire les espaces aux extrémités)
print(texto.replace("o", "0"))  # "  B0nj0ur M0nde  "
```

{/* sol:

<Pitfall>
Les méthodes de chaîne **ne modifient pas** la variable : `texto.upper()` ne change pas `texto`, elle
renvoie une nouvelle chaîne. Si tu veux la garder, réaffecte : `texto = texto.upper()`.
</Pitfall>

## `split` et `join` — du texte à la liste et retour

`split()` découpe une chaîne en une liste ; `join()` réunit une liste en une chaîne :

```python
frase = "un deux trois"
palabras = frase.split()        # ['un', 'deux', 'trois']
print(len(palabras))            # 3

partes = ["2024", "07", "05"]
print("-".join(partes))         # 2024-07-05
```

## Chercher et remplacer

```python
correo = "ana@exemple.com"
print(correo.startswith("ana"))   # True
print("@" in correo)              # True
print(correo.find("@"))           # 3   (position du @)
print(correo.replace(".com", ".es"))  # ana@exemple.es
```
