# Cadenas de texto

<Accroche>« El texto es datos. Y Python tiene herramientas afiladas para cortarlo, medirlo y transformarlo. »</Accroche>

Una **cadena** (*string*) es una secuencia de caracteres. Por dentro se comporta como una lista de
letras: puedes indexarla, rebanarla y medir su longitud.

```python
saludo = "Python"
print(len(saludo))   # 6
print(saludo[0])     # P
print(saludo[-1])    # n
print(saludo[0:3])   # Pyt   (rebanada, como en las listas)
```

## f-strings — el formateo moderno

Una **f-string** empieza por `f` y mete variables entre llaves. Es la forma más limpia de construir
texto:

```python
nombre = "Ada"
edad = 36
print(f"{nombre} tiene {edad} años")   # Ada tiene 36 años
```

## Métodos de texto

Las cadenas traen muchos métodos. Ninguno cambia la cadena original (son **inmutables**): todos
**devuelven una nueva**.

```python
texto = "  Hola Mundo  "
print(texto.upper())        # "  HOLA MUNDO  "
print(texto.lower())        # "  hola mundo  "
print(texto.strip())        # "Hola Mundo"   (quita espacios de los extremos)
print(texto.replace("o", "0"))  # "  H0la Mund0  "
```

{/* sol:
saludo = "hola"

<Pitfall>
Los métodos de cadena **no modifican** la variable: `texto.upper()` no cambia `texto`, devuelve una
nueva cadena. Si quieres conservarla, reasigna: `texto = texto.upper()`.
</Pitfall>

## `split` y `join` — de texto a lista y vuelta

`split()` parte una cadena en una lista; `join()` une una lista en una cadena:

```python
frase = "uno dos tres"
palabras = frase.split()        # ['uno', 'dos', 'tres']
print(len(palabras))            # 3

partes = ["2024", "07", "05"]
print("-".join(partes))         # 2024-07-05
```

## Buscar y reemplazar

```python
correo = "ana@ejemplo.com"
print(correo.startswith("ana"))   # True
print("@" in correo)              # True
print(correo.find("@"))           # 3   (posición del @)
print(correo.replace(".com", ".es"))  # ana@ejemplo.es
```
