Ya sabes crear clases y heredar. Este capítulo trata de **diseñar bien**: cuándo componer en vez de

## Composición: "tiene un"

La herencia dice "**es un**" (`Gato` es un `Animal`). La **composición** dice "**tiene un**": un objeto
se construye con otros objetos. Suele ser más flexible que la herencia.

```python
class Motor:
    def arrancar(self):
        return "brum"

class Coche:
    def __init__(self):
        self.motor = Motor()      # un Coche TIENE UN Motor
    def arrancar(self):
        return self.motor.arrancar()

print(Coche().arrancar())   # brum
```

## `@property` — atributos calculados

Un `@property` es un método que se usa **como si fuera un atributo** (sin paréntesis). Ideal para
valores derivados:

```python
class Circulo:
    def __init__(self, radio):
        self.radio = radio

    @property
    def diametro(self):
        return self.radio * 2

c = Circulo(5)
print(c.diametro)   # 10   (¡sin paréntesis!)
```

class Circulo:
    def __init__(self, radio):
        self.radio = radio

print(Circulo(5).diametro)
*/}

## `dataclasses` — clases de datos sin ceremonia

Cuando una clase es sobre todo **datos**, `@dataclass` te escribe el `__init__`, el `__repr__` y el
`__eq__` gratis:

```python
from dataclasses import dataclass

@dataclass
class Punto:
    x: int
    y: int

p = Punto(3, 4)
print(p)          # Punto(x=3, y=4)   (¡__repr__ automático!)
print(p == Punto(3, 4))   # True      (__eq__ automático)
```

{/* sol:

@dataclass

<Pitfall>
No abuses de la herencia. Antes de crear una jerarquía de cinco niveles, pregúntate si no es más claro
**componer** objetos pequeños. Regla práctica: *composición sobre herencia*.
</Pitfall>

<Collapsible title="2. Una property con validación al asignar (setter).">

```python
class Temperatura:
    def __init__(self, celsius):
        self._celsius = celsius
    @property
    def celsius(self):
        return self._celsius
    @celsius.setter
    def celsius(self, valor):
        if valor < -273.15:
            raise ValueError("por debajo del cero absoluto")
        self._celsius = valor
```
