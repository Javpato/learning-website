Ejercicio 5 — Suma recursiva de un arreglo

Enunciado

/** Suma recursiva de los n primeros elementos de un arreglo.
 * @param[in] t un arreglo de enteros (pasado por decrecimiento en puntero).
 * @param[in] n el número de elementos a sumar (≥ 0).
 * @return la suma t[0] + t[1] + ... + t[n-1].
 **/
int somme(int t[], int n) {
  if (n == 0) return 0;
  return t[n - 1] + somme(t, n - 1);
}
int T[4] = {5, 2, 7, 3};
int s = somme(T, 4);
  1. Seguir la evolución de la pila durante la llamada a somme(T, 4).
  2. ¿Cuál es el caso base?
  3. ¿Cómo se comparte el arreglo entre los frames? (pista: decrecimiento en puntero)
