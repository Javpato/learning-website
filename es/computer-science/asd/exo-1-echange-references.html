Ejercicio 1 — Intercambio por referencia

Enunciado

Se escribe en C++ la función:

/** Intercambia los contenidos de dos variables
 * @param[in/out] a, b dos variables enteras.
 **/
void echange(int &a, int &b) {
  int t = a;
  a = b;
  b = t;
}

Se llama a echange(x, y) desde main, con x = 3, y = 7. (El nombre de la función es echange sin tilde: C++ no permite caracteres acentuados en los identificadores.)

  1. Describir el estado de la pila en cada paso.
  2. ¿Por qué es indispensable aquí el paso por referencia?
