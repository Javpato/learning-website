Ejercicio 2 — Intercambio por punteros (C)

Enunciado

En C, las referencias no existen. Para que una función modifique una variable de quien la llama, hay que pasarle su dirección.

/** Intercambia los contenidos apuntados por dos punteros enteros.
 * @param[in/out] x, y dos punteros a enteros (no NULL).
 **/
void echange(int *x, int *y) {
  int t;
  t = *x;
  *x = *y;
  *y = t;
}
/* llamada */
echange(&a, &b);
