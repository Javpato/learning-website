Ejercicio 3 — Alias vs copia

Enunciado

Sea:

int a = 1, b = 3;
int *p = &a, *q = &b;

¿Qué ocurre por separado después de cada una de las siguientes asignaciones?

  1. *p = *q;
  2. p = q;

En cada caso: ¿qué variables han cambiado? ¿Hacia qué apuntan p y q?
