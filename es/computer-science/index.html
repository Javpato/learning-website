Informática

Algoritmos que puedes recorrer paso a paso, estructuras de datos que puedes explorar y algunos proyectos que vale la pena mostrar.

Redes — del cable a TCP

El módulo de Redes de L2 reconstruido como curso interactivo: conmutación, capas, codificación, HDLC, direccionamiento IP, enrutamiento, TCP. Cada mecanismo se calcula a mano y se manipula en un simulador; TD resueltos y exámenes de práctica incluidos. En francés, inglés y español.
▤

SQL — De cero a experto

Curso interactivo: ejecuta SQL real en tu navegador (motor SQLite). SELECT, filtros, joins, funciones y agregación — 6 capítulos, con un proyecto práctico al final de cada uno.

Python — De cero a programador

Curso interactivo al estilo Pokémon: ejecuta Python real en tu navegador. Fundamentos, estructuras de datos, orientación a objetos y Python avanzado — completa cada nivel, gana tu medalla y desbloquea proyectos guiados que subes a tu GitHub, hasta un proyecto final ambicioso.

ASD — Algorítmica y Estructuras de Datos

Curso animado sobre la pila, el heap y los punteros. Ejercicios paso a paso con diagramas de memoria (referencias, punteros, funciones recursivas).
