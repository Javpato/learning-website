Diagonalizabilidad

«Diagonalizable = existe un sistema de referencia donde la transformación actúa por separado sobre cada eje.»

Intuición

Una aplicación diagonalizable posee direcciones privilegiadas independientes que permanecen sobre sí mismas. Sobre cada una de estas direcciones, la aplicación solo estira, contrae, invierte el sentido o anula. En la base adecuada, ya no hay mezcla entre coordenadas; cada coordenada evoluciona por separado:

$$(x_1, \dots, x_n) \mapsto (\lambda_1 x_1, \dots, \lambda_n x_n).$$

Por eso «diagonalizable» casi siempre significa «comprensible mediante un cambio de sistema de referencia»: en un mal sistema de referencia la transformación parece complicada; en el bueno, se vuelve «eje por eje».

Definición formal

Una aplicación lineal $T \colon V \to V$ es diagonalizable si existe una base de $V$ en la cual la matriz de $T$ es diagonal. De forma equivalente, existe una base formada enteramente por vectores propios de $T$. Para las matrices, esto equivale a decir que existe una matriz invertible $P$ tal que

$$P^{-1} A P = D, \qquad D \text{ diagonal}.$$

Ejemplo calculado — una matriz simétrica real

Las matrices simétricas reales son el mejor punto de partida: son ortogonalmente diagonalizables — se puede elegir una base ortonormal de vectores propios, por lo que el cambio de base no añade ninguna distorsión debida al sistema de referencia. Tomemos

$$A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}.$$

Su polinomio característico es

$$\chi_A(\lambda) = (2-\lambda)^2 - 1 = (\lambda - 3)(\lambda - 1),$$

de donde dos valores propios $\lambda_1 = 3$ y $\lambda_2 = 1$, con vectores propios $v_1 = (1, 1)$ y $v_2 = (1, -1)$ — que son ortogonales. En la base $(v_1, v_2)$, la aplicación se reduce simplemente a «multiplicar la primera coordenada por 3 y conservar la segunda»:

$$P^{-1} A P = \begin{pmatrix} 3 & 0 \\ 0 & 1 \end{pmatrix}, \qquad P = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}.$$

Visualización interactiva

Las dos vistas muestran el mismo operador. A la izquierda, el sistema de referencia estándar: la malla se deforma y la transformación parece mezclar las coordenadas. A la derecha, la base propia: la acción es «eje por eje». Prueba también el cizallamiento — conserva una dirección propia real pero no es diagonalizable.

El contraejemplo que hay que conocer — el cizallamiento

La matriz de cizallamiento

$$S = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$$

deforma la cuadrícula, conserva una dirección propia real (el eje $e_1$, con $\lambda = 1$), pero sigue mezclando las coordenadas: su única recta propia es de dimensión 1, demasiado pequeña para generar el plano. Por tanto no existe ninguna base de vectores propios — $S$ no es diagonalizable. Es el contraste ideal con una matriz verdaderamente diagonal o simétrica.

Errores clásicos

Tener valores propios reales no basta. El cizallamiento tiene un valor propio real (¡doble!) y sin embargo no es diagonalizable: hace falta que los espacios propios sean suficientemente grandes para reconstituir todo el espacio (la suma de sus dimensiones debe valer $n$).

Diagonalizable no significa invertible. $\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ es diagonal (por tanto diagonalizable) pero no invertible; a la inversa, el cizallamiento es invertible pero no diagonalizable. Las dos nociones son independientes.

Mini-ejercicios

Diagonalizar $\begin{pmatrix} 3 & 0 \\ 0 & -1 \end{pmatrix}$.

¡Ya es diagonal! La base canónica es una base propia: $e_1$ para $\lambda = 3$ (estiramiento) y $e_2$ para $\lambda = -1$ (reflexión). Toda matriz diagonal es diagonalizable, con $P = I$.

¿Por qué $\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$ no es diagonalizable?

Es nilpotente no nula: su único valor propio es $0$. Si fuera diagonalizable, sería semejante a la matriz nula, por tanto nula — contradicción. (Es el puente con la página nilpotencia.)

Si una matriz $n \times n$ tiene $n$ valores propios distintos, ¿por qué es diagonalizable?

Los vectores propios asociados a valores propios distintos son linealmente independientes. Con $n$ valores propios distintos se obtienen $n$ vectores propios independientes — es una base propia. Cuidado, el recíproco es falso: la identidad es diagonalizable con un único valor propio.
