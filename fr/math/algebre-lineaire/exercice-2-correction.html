Correction écrite — Exercice 2

Le texte complet, à lire calmement. Pour la version pas-à-pas avec figures, voir la correction animée.

1. Linéarité de D

La dérivation respecte sommes et multiples scalaires : pour $p, q \in \mathbb{R}_n[X]$ et $a, b \in \mathbb{R}$,

$$\boxed{D(ap + bq) = (ap + bq)' = a\,p' + b\,q' = a\,D(p) + b\,D(q)}$$

De plus, dériver fait baisser le degré : si $\deg p \le n$ alors $\deg p' \le n - 1 \le n$, donc $D$ envoie bien $\mathbb{R}_n[X]$ dans lui-même. C'est un endomorphisme d'un espace de dimension $n + 1$.

2. Matrice de D dans la base canonique

La colonne $k$ de la matrice contient les coordonnées de l'image du $k$-ième vecteur de base. Or

$$D(1) = 0, \qquad D(X^k) = k\,X^{k-1} \quad (k \ge 1).$$

Chaque monôme descend d'un cran, multiplié par son exposant. Pour $n = 3$, dans la base $(1, X, X^2, X^3)$ :

$$\operatorname{Mat}(D) = \begin{pmatrix} 0 & 1 & 0 & 0 \\ 0 & 0 & 2 & 0 \\ 0 & 0 & 0 & 3 \\ 0 & 0 & 0 & 0 \end{pmatrix}.$$

Les coefficients $1, 2, \dots, n$ occupent la surdiagonale ; tout le reste est nul. La matrice est triangulaire supérieure stricte : sa diagonale est entièrement nulle.

3. Nilpotence d'ordre exactement n + 1

Chaque application de $D$ fait chuter le degré d'au moins 1 :

$$\mathbb{R}_n[X] \xrightarrow{\;D\;} \mathbb{R}_{n-1}[X] \xrightarrow{\;D\;} \cdots \xrightarrow{\;D\;} \mathbb{R}_0[X] \xrightarrow{\;D\;} \{0\}.$$

Après $n+1$ applications, tout polynôme de degré $\le n$ est annulé :

$$\boxed{D^{n+1} = 0}$$

L'ordre est exactement $n + 1$ car $D^n \neq 0$. En effet, en dérivant $k$ fois le monôme dominant :

$$D^k(X^n) = n(n-1)\cdots(n-k+1)\,X^{n-k}, \qquad \text{donc} \qquad D^n(X^n) = n! \neq 0.$$

$D$ est nilpotent d'ordre $n + 1$ — qui est bien $\le \dim \mathbb{R}_n[X] = n+1$, conformément à la borne générale sur l'indice de nilpotence.

4. Valeurs propres de D

La matrice de $D$ est triangulaire : ses valeurs propres se lisent sur la diagonale, qui est entièrement nulle. Donc

$$\boxed{\operatorname{Sp}(D) = \{0\}}$$

(On peut aussi le voir directement : si $D(p) = \lambda p$ avec $p \neq 0$ et $\lambda \neq 0$, alors $\deg p' = \deg p$, ce qui est impossible puisque dériver fait strictement chuter le degré. Et $0$ est bien valeur propre : les constantes vérifient $D(c) = 0$.)

5. D n'est pas diagonalisable

Raisonnons par l'absurde : supposons $D$ diagonalisable. Sa seule valeur propre étant $0$, il existerait une base dans laquelle sa matrice est $\operatorname{diag}(0, \dots, 0)$, c'est-à-dire la matrice nulle. On aurait alors

$$D = P \cdot 0 \cdot P^{-1} = 0.$$

Or $D$ n'est pas l'application nulle dès que $n \ge 1$ : par exemple

$$D(X) = 1 \neq 0.$$

Contradiction. Donc

$$\boxed{D \text{ n'est pas diagonalisable (pour } n \ge 1\text{)}}$$

C'est l'illustration parfaite du principe général vu sur la page nilpotence : un nilpotent non nul n'est jamais diagonalisable.
