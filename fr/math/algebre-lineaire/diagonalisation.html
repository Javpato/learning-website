Diagonalisabilité

« Diagonalisable = il existe un repère où la transformation agit séparément sur chaque axe. »

Intuition

Une application diagonalisable possède des directions privilégiées indépendantes qui restent sur elles-mêmes. Sur chacune de ces directions, l'application ne fait qu'étirer, contracter, inverser le sens, ou annuler. Dans la bonne base, il n'y a plus de mélange entre coordonnées ; chaque coordonnée évolue séparément :

$$(x_1, \dots, x_n) \mapsto (\lambda_1 x_1, \dots, \lambda_n x_n).$$

C'est pour cela que « diagonalisable » veut presque toujours dire « compréhensible par changement de repère » : dans un mauvais repère la transformation semble compliquée ; dans le bon repère, elle devient « axe par axe ».

Définition formelle

Une application linéaire $T \colon V \to V$ est diagonalisable s'il existe une base de $V$ dans laquelle la matrice de $T$ est diagonale. De façon équivalente, il existe une base entièrement formée de vecteurs propres de $T$. Pour les matrices, cela revient à dire qu'il existe une matrice inversible $P$ telle que

$$P^{-1} A P = D, \qquad D \text{ diagonale}.$$

Exemple calculé — une matrice symétrique réelle

Les matrices symétriques réelles sont le meilleur point de départ : elles sont orthogonalement diagonalisables — on peut choisir une base orthonormale de vecteurs propres, donc le changement de base n'ajoute aucune distorsion due au repère. Prenons

$$A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}.$$

Son polynôme caractéristique est

$$\chi_A(\lambda) = (2-\lambda)^2 - 1 = (\lambda - 3)(\lambda - 1),$$

d'où deux valeurs propres $\lambda_1 = 3$ et $\lambda_2 = 1$, avec pour vecteurs propres $v_1 = (1, 1)$ et $v_2 = (1, -1)$ — qui sont orthogonaux. Dans la base $(v_1, v_2)$, l'application devient simplement « multiplier la première coordonnée par 3 et garder la seconde » :

$$P^{-1} A P = \begin{pmatrix} 3 & 0 \\ 0 & 1 \end{pmatrix}, \qquad P = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}.$$

Visualisation interactive

Les deux vues montrent le même opérateur. À gauche, le repère standard : la grille se déforme et la transformation semble mélanger les coordonnées. À droite, la base propre : l'action est « axe par axe ». Essaie aussi le cisaillement — il garde une direction propre réelle mais n'est pas diagonalisable.

Le contre-exemple à connaître — le cisaillement

La matrice de cisaillement

$$S = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$$

déforme le quadrillage, garde une direction propre réelle (l'axe $e_1$, avec $\lambda = 1$), mais mélange encore les coordonnées : sa seule droite propre est de dimension 1, trop petite pour engendrer le plan. Il n'existe donc pas de base de vecteurs propres — $S$ n'est pas diagonalisable. C'est le contraste idéal avec une matrice vraiment diagonale ou symétrique.

Pièges classiques

Avoir des valeurs propres réelles ne suffit pas. Le cisaillement a une valeur propre réelle (double !) et n'est pourtant pas diagonalisable : il faut que les espaces propres soient assez gros pour reconstituer tout l'espace (la somme de leurs dimensions doit valoir $n$).

Diagonalisable ne veut pas dire inversible. $\begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$ est diagonale (donc diagonalisable) mais non inversible ; à l'inverse, le cisaillement est inversible mais non diagonalisable. Les deux notions sont indépendantes.

Mini-exercices

Diagonaliser $\begin{pmatrix} 3 & 0 \\ 0 & -1 \end{pmatrix}$.

Elle est déjà diagonale ! La base canonique est une base propre : $e_1$ pour $\lambda = 3$ (étirement) et $e_2$ pour $\lambda = -1$ (réflexion). Toute matrice diagonale est diagonalisable, avec $P = I$.

Pourquoi $\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$ n'est-elle pas diagonalisable ?

Elle est nilpotente non nulle : sa seule valeur propre est $0$. Si elle était diagonalisable, elle serait semblable à la matrice nulle, donc nulle — contradiction. (C'est le pont avec la page nilpotence.)

Si une matrice $n \times n$ a $n$ valeurs propres distinctes, pourquoi est-elle diagonalisable ?

Des vecteurs propres associés à des valeurs propres distinctes sont linéairement indépendants. Avec $n$ valeurs propres distinctes on obtient $n$ vecteurs propres indépendants — c'est une base propre. Attention, la réciproque est fausse : l'identité est diagonalisable avec une seule valeur propre.
