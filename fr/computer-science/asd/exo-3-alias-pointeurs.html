Exo 3 — Alias vs copie

Énoncé

Soit :

int a = 1, b = 3;
int *p = &a, *q = &b;

Que se passe-t-il séparément après chacune des affectations suivantes ?

  1. *p = *q;
  2. p = q;

Dans chaque cas : quelles variables ont changé ? Vers quoi pointent p et q ?
