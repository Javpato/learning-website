Correction écrite — Exercice 2

Texte intégral, à lire calmement. Pour visualiser le cycle et la comparaison avec AE, ouvre la version animée.

Convention et relations utiles

On adopte la convention des grandeurs reçues par le gaz : $\Delta U = W + Q$, $\delta W = -P\,dV$. Pour un gaz parfait à une mole, $PV = RT$ et $\Delta U = C_V(T_f - T_i)$. La relation de Mayer donne $C_p - C_V = R$, et on note $\gamma = C_p / C_V$, soit $C_V = R/(\gamma - 1)$ et $C_p = \gamma R / (\gamma - 1)$.

États successifs

À l'état $A = (V_A, P_A, T_A)$, $T_A = P_A V_A / R$.

$A \to B$ isochore avec $P_B = 2P_A$ : $V_B = V_A$, $T_B = 2T_A$. Donc $B = (V_A,\,2P_A)$.

$B \to C$ isobare avec $V_C = 2V_A$ : $P_C = 2P_A$, $T_C = 4T_A$. Donc $C = (2V_A,\,2P_A)$.

$C \to D$ isotherme avec $V_D = 3V_A$ : $T_D = T_C = 4T_A$. Comme $P_D V_D = R T_D = 4R T_A$ :

$$\boxed{P_D = \frac{4}{3}P_A},\qquad D = \left(3V_A,\,\frac{4}{3}P_A\right).$$

Question 1 — Pression $P_E$

$D \to E$ est une adiabatique réversible : $PV^\gamma = \text{cst}$, donc $P_E = P_D\,(V_D/V_E)^\gamma$. L'énoncé donne $V_E = (4/3)^{1/\gamma}\,V_D$, donc :

$$\frac{V_D}{V_E} = \left(\frac{4}{3}\right)^{-1/\gamma},\qquad \left(\frac{V_D}{V_E}\right)^\gamma = \left(\frac{4}{3}\right)^{-1} = \frac{3}{4}.$$

Par conséquent $P_E = (4/3)P_A \cdot 3/4$, soit :

$$\boxed{P_E = P_A}.$$

La température correspondante vaut $T_E = P_A V_E / R = 3\,(4/3)^{1/\gamma}\,T_A$.

Diagramme de Clapeyron

Visuellement : $A \to B$ verticale (V cst), $B \to C$ horizontale vers la droite (P cst), $C \to D$ hyperbole décroissante (isotherme), $D \to E$ courbe plus pentue que l'isotherme (adiabatique). Le point $E$ retombe sur la même horizontale que $A$, puisque $P_E = P_A$.

Question 3 — Bilan transformation par transformation

$A \to B$ — isochore

$$W_{AB} = 0,\qquad \Delta U_{AB} = C_V(T_B - T_A) = C_V T_A,\qquad Q_{AB} = \Delta U_{AB} = C_V T_A.$$

Le piston ne se déplace pas, toute la chaleur reçue augmente l'énergie interne.

$B \to C$ — isobare

$W_{BC} = -P_B(V_C - V_B) = -2P_A V_A = -2RT_A$ (détente, le gaz fournit du travail).

$\Delta U_{BC} = C_V(T_C - T_B) = 2C_V T_A$.

$Q_{BC} = \Delta U_{BC} - W_{BC} = 2C_V T_A + 2RT_A = 2(C_V + R)T_A = 2C_p T_A$.

$C \to D$ — isotherme

$T = 4T_A$, donc $P(V) = 4RT_A / V$. Travail :

$$W_{CD} = -\!\int_{V_C}^{V_D}\!\frac{4RT_A}{V}\,dV = -4RT_A\,\ln\!\frac{3V_A}{2V_A} = -4RT_A\,\ln\!\frac{3}{2}.$$

$\Delta U_{CD} = 0$ (T constant), donc $Q_{CD} = -W_{CD} = 4RT_A\,\ln(3/2)$.

$D \to E$ — adiabatique réversible

$Q_{DE} = 0$ par définition. Et $\Delta U_{DE} = W_{DE} = C_V(T_E - T_D) = C_V T_A\!\left[3(4/3)^{1/\gamma} - 4\right]$.

Variation totale d'énergie interne

$U$ est une fonction d'état :

$$\boxed{\Delta U_{ABCDE} = C_V(T_E - T_A) = C_V T_A\!\left[3\!\left(\frac{4}{3}\right)^{\!1/\gamma}\!-\,1\right]}.$$

On peut vérifier en sommant $\Delta U$ étape par étape : $C_V T_A + 2C_V T_A + 0 + C_V T_A[3(4/3)^{1/\gamma} - 4] = C_V T_A[3(4/3)^{1/\gamma} - 1]$.

Question 4 — Transformation directe AE

Comme $P_E = P_A$, le chemin direct $A \to E$ est une isobare à pression $P_A$. Donc :

$$W_{AE} = -P_A(V_E - V_A) = -R(T_E - T_A),\qquad \Delta U_{AE} = C_V(T_E - T_A),\qquad Q_{AE} = C_p(T_E - T_A).$$

Question 5 — Comparaison graphique

Sur le diagramme, le chemin $ABCDE$ passe au-dessus du chemin $AE$ (les états $B$, $C$, $D$ sont à des pressions plus élevées que $P_A$). L'aire sous $ABCDE$ est donc plus grande que l'aire sous $AE$. Comme le travail reçu est l'opposé de l'aire (avec un signe positif si compression, négatif si détente), et que les deux chemins sont globalement des détentes :

$$\boxed{W_{ABCDE} < W_{AE} < 0}.$$

Le gaz fournit plus de travail au milieu extérieur en empruntant le détour $ABCDE$.

En revanche, l'énergie interne ne dépend que des états initial et final :

$$\boxed{\Delta U_{ABCDE} = \Delta U_{AE} = C_V(T_E - T_A)}.$$

C'est la signature même d'une fonction d'état, par opposition à $W$ et $Q$ qui dépendent du chemin. Cette distinction est centrale en thermodynamique.
