Correction écrite — Exercice 1

Texte intégral, à lire calmement. Pour visualiser les trois chemins et leurs aires, ouvre la version animée.

1. Analyse des états A, B et C

Le gaz est supposé parfait, donc il vérifie l'équation d'état $PV = nRT$. Avec $n = 2$, on a $PV = 2RT$.

À l'état $A$ : $P_A V_A = 2RT_A$. À l'état $B$ : $P_B V_B = 2RT_B$. Or l'énoncé donne $T_B = T_A$, donc $P_B V_B = 2RT_A$, et par conséquent :

$$P_A V_A = P_B V_B.$$

Comme $P_B = 3P_A$, on obtient $P_A V_A = 3 P_A V_B$, soit, après simplification :

$$\boxed{V_B = \frac{V_A}{3}}.$$

Les coordonnées thermodynamiques des deux états sont donc $A = (V_A, P_A)$ et $B = \left(\dfrac{V_A}{3},\,3P_A\right)$.

Position du point C

Le chemin $ACB$ est une isochore $A \to C$ suivie d'une isobare $C \to B$. Donc $V_C = V_A$ (volume constant) et $P_C = P_B = 3P_A$ (pression constante). Ainsi :

$$\boxed{C = (V_A,\,3P_A)}.$$

2. Convention de signe et premier principe

L'énoncé demande les travaux et chaleurs reçus par le gaz. Avec cette convention :

$$\Delta U = W + Q,\qquad \delta W = -P\,dV,\qquad W = -\!\int_{V_i}^{V_f}\! P\,dV.$$

Une compression ($dV < 0$) donne $W > 0$ : le gaz reçoit du travail. Une détente ($dV > 0$) donne $W < 0$. Ici, $V_B = V_A/3 < V_A$ — chaque chemin est globalement une compression, donc on s'attend à $W > 0$ pour les trois chemins.

Pourquoi ΔU = 0

Pour un gaz parfait, l'énergie interne ne dépend que de la température : $\Delta U = nC_V(T_B - T_A)$. Or $T_B = T_A$, donc :

$$\Delta U_{A\to B} = 0.$$

Cette conclusion est valable pour les trois chemins, car $U$ est une fonction d'état : seules comptent les températures initiale et finale. D'après le premier principe, $W + Q = 0$ pour chaque chemin, donc $\boxed{Q = -W}$.

Question 1 — Équation de l'isotherme AMB

La transformation $AMB$ est isotherme ($T = T_A$). Pour un gaz parfait, $PV = nRT$, ce qui donne ici :

$$\boxed{PV = 2RT_A},\qquad \text{soit}\qquad P(V) = \frac{2RT_A}{V}.$$

C'est une hyperbole équilatère décroissante dans le diagramme $(P, V)$. On vérifie que $A$ et $B$ y appartiennent : pour $A$, $P_A V_A = 2RT_A$ ; pour $B$, $P_B V_B = 3P_A \cdot V_A/3 = P_A V_A = 2RT_A$.

Chemin AMB — transformation isotherme

Travail reçu

Sur l'isotherme, $P(V) = 2RT_A / V$, donc :

$$W_{AMB} = -\!\int_{V_A}^{V_B}\!\frac{2RT_A}{V}\,dV = -2RT_A\,\bigl[\ln V\bigr]_{V_A}^{V_B} = -2RT_A\,\ln\!\frac{V_B}{V_A}.$$

Comme $V_B/V_A = 1/3$ et $\ln(1/3) = -\ln 3$ :

$$\boxed{W_{AMB} = 2RT_A\,\ln 3 \approx 5{,}49\ \text{kJ}}.$$

Chaleur reçue

Avec $\Delta U = 0$, on a $Q_{AMB} = -W_{AMB}$ :

$$\boxed{Q_{AMB} = -2RT_A\,\ln 3 \approx -5{,}49\ \text{kJ}}.$$

La chaleur reçue est négative : pendant cette compression isotherme, le gaz reçoit du travail et cède exactement la même énergie sous forme de chaleur au thermostat — l'énergie interne reste constante.

Chemin ACB — isochore puis isobare

Étape A → C : isochore

Le volume est constant ($V = V_A$, $dV = 0$), donc :

$$\boxed{W_{AC} = 0}.$$

Le piston ne se déplace pas — il n'y a aucun travail mécanique des forces de pression.

Étape C → B : isobare

La pression vaut $P = P_B = 3P_A$ et le volume passe de $V_A$ à $V_A/3$ :

$$W_{CB} = -P_B(V_B - V_C) = -3P_A\!\left(\frac{V_A}{3} - V_A\right) = 2P_A V_A.$$

En utilisant $P_A V_A = 2RT_A$ :

$$W_{CB} = 4RT_A.$$

Bilan ACB : $W_{ACB} = W_{AC} + W_{CB}$, donc :

$$\boxed{W_{ACB} = 4RT_A \approx 9{,}98\ \text{kJ}},\qquad \boxed{Q_{ACB} = -4RT_A \approx -9{,}98\ \text{kJ}}.$$

Physiquement, ce chemin impose une compression à pression élevée (sur l'isobare $C \to B$). Le travail reçu y est donc particulièrement important.

Chemin ANB — droite dans le diagramme (P, V)

Sur une droite reliant $A$ à $B$, $P$ varie linéairement avec $V$. L'aire sous la courbe est l'aire d'un trapèze :

$$\int_{V_A}^{V_B}\! P(V)\,dV = \frac{P_A + P_B}{2}\,(V_B - V_A).$$

Donc :

$$W_{ANB} = -\frac{P_A + 3P_A}{2}\!\left(\frac{V_A}{3} - V_A\right) = -2P_A\!\left(-\frac{2V_A}{3}\right) = \frac{4}{3}P_A V_A = \frac{8}{3}RT_A.$$ $$\boxed{W_{ANB} = \frac{8}{3}RT_A \approx 6{,}66\ \text{kJ}},\qquad \boxed{Q_{ANB} = -\frac{8}{3}RT_A \approx -6{,}66\ \text{kJ}}.$$

Comparaison finale

On compare les coefficients en $RT_A$ :

$$2\ln 3 \approx 2{,}20,\qquad \frac{8}{3} \approx 2{,}67,\qquad 4.$$

D'où l'inégalité graphiquement évidente sur les aires :

$$\boxed{W_{AMB} < W_{ANB} < W_{ACB}}.$$

Et puisque $Q = -W$ pour chaque chemin, l'ordre des chaleurs est inversé :

$$\boxed{Q_{ACB} < Q_{ANB} < Q_{AMB} < 0}.$$

Les trois chaleurs sont négatives : dans les trois cas, le gaz cède de la chaleur au milieu extérieur. Le chemin qui reçoit le plus de travail (ACB) est aussi celui qui cède le plus de chaleur, ce qui est cohérent avec $\Delta U = 0$.
