Correction écrite — Exercice 4

Texte intégral, à lire calmement. Si tu préfères voir le circuit bouger et chaque transformation expliquée, ouvre la version animée.

a) Diviseur de courant — mise en quadrature

Mise en équation des deux branches

Les deux branches sont en parallèle, alimentées par la même tension $\underline{U}$ (notation complexe). Branche 1 : la bobine seule, modélisée en $RL$ série. Branche 2 : la même bobine en série avec le condensateur $C$.

$$\underline{Z_1} = R + j\omega L,\qquad \underline{Z_2} = R + j\omega L + \frac{1}{j\omega C}.$$

On rappelle que $\dfrac{1}{j} = -j$ car $j \cdot j = -1$. Donc :

$$\frac{1}{j\omega C} = -\frac{j}{\omega C},\qquad \underline{Z_2} = R + j\!\left(\omega L - \frac{1}{\omega C}\right).$$

1. Avance ou retard ? Forme du rapport

Comme les deux branches voient la même tension $\underline{U}$, on a $\underline{I_1} = \underline{U}/\underline{Z_1}$ et $\underline{I_2} = \underline{U}/\underline{Z_2}$, donc :

$$\frac{\underline{I_1}}{\underline{I_2}} = \frac{\underline{U}/\underline{Z_1}}{\underline{U}/\underline{Z_2}} = \frac{\underline{Z_2}}{\underline{Z_1}}.$$

Le condensateur en série introduit un terme capacitif négatif $-\dfrac{1}{\omega C}$ qui s'ajoute à la réactance inductive $\omega L$. La branche 2 est donc « moins inductive » (voire capacitive) que la branche 1. En conséquence, $i_2$ est en avance sur $i_1$ — c'est exactement ce que traduit l'écriture $\dfrac{\underline{I_1}}{\underline{I_2}} = -jk$ avec $k > 0$ : multiplier par $-j$ revient à un retard de $90^\circ$, donc $\underline{I_1}$ est en retard de $90^\circ$ sur $\underline{I_2}$.

2. Détermination de C par le diviseur de courant

On veut que le rapport $\dfrac{\underline{Z_2}}{\underline{Z_1}}$ soit un imaginaire pur négatif. On multiplie haut et bas par le conjugué de $\underline{Z_1}$ :

$$\frac{\underline{Z_2}}{\underline{Z_1}} = \frac{\underline{Z_2}\,\overline{\underline{Z_1}}}{|\underline{Z_1}|^2} = \frac{\bigl[R + j(\omega L - 1/\omega C)\bigr]\,(R - j\omega L)}{R^2 + (\omega L)^2}.$$

Développons le numérateur (on note $X_2 = \omega L - 1/(\omega C)$ pour alléger) :

$$(R + jX_2)(R - j\omega L) = R^2 + X_2\,\omega L + j\bigl(R X_2 - R\,\omega L\bigr).$$

Pour que le rapport soit imaginaire pur, la partie réelle doit s'annuler :

$$R^2 + X_2\,\omega L = 0 \;\Longleftrightarrow\; X_2 = -\frac{R^2}{\omega L} \;\Longleftrightarrow\; \omega L - \frac{1}{\omega C} = -\frac{R^2}{\omega L}.$$

On isole $\dfrac{1}{\omega C}$ :

$$\frac{1}{\omega C} = \omega L + \frac{R^2}{\omega L} = \frac{(\omega L)^2 + R^2}{\omega L}.$$

D'où enfin :

$$\boxed{\,C = \frac{L}{R^2 + (\omega L)^2}\,}$$

3. Valeur du facteur k

Avec cette valeur de $C$, la partie réelle est nulle. Reste le coefficient imaginaire :

$$\frac{\underline{I_1}}{\underline{I_2}} = j\,\frac{R(X_2 - \omega L)}{R^2 + (\omega L)^2}.$$

Comme $X_2 = -R^2/(\omega L)$, on calcule $X_2 - \omega L = -R^2/(\omega L) - \omega L = -\bigl[R^2 + (\omega L)^2\bigr]/(\omega L)$. Donc :

$$\frac{\underline{I_1}}{\underline{I_2}} = j\cdot\frac{R\cdot\bigl(-[R^2+(\omega L)^2]/(\omega L)\bigr)}{R^2+(\omega L)^2} = -j\,\frac{R}{\omega L}.$$

On lit donc :

$$\boxed{\,k = \frac{R}{\omega L}\,}$$

b) Diviseur de tension

Schéma équivalent

La source de tension $\underline{U}$ alimente, en série, l'impédance de ligne $\underline{Z}_\text{ligne} = R + jX_L = 1 + j\,0{,}5\ \Omega$ puis le récepteur $\underline{Z_2} = 25\,e^{j\pi/3}\ \Omega$. La tension cherchée $\underline{U_2}$ est aux bornes de $\underline{Z_2}$.

1. Valeur efficace U₂ par diviseur de tension

$$\underline{U_2} = \underline{U}\cdot\frac{\underline{Z_2}}{\underline{Z}_\text{ligne} + \underline{Z_2}}.$$

On exprime $\underline{Z_2}$ sous forme cartésienne pour faire la somme :

$$\underline{Z_2} = 25\bigl(\cos(60^\circ) + j\sin(60^\circ)\bigr) = 25\,(0{,}5 + j\,0{,}8660) = 12{,}5 + j\,21{,}65\ \Omega.$$

D'où :

$$\underline{Z}_\text{ligne} + \underline{Z_2} = (1 + 12{,}5) + j(0{,}5 + 21{,}65) = 13{,}5 + j\,22{,}15\ \Omega.$$

Modules :

$$|\underline{Z_2}| = 25\ \Omega,\qquad |\underline{Z}_\text{ligne} + \underline{Z_2}| = \sqrt{13{,}5^2 + 22{,}15^2} = \sqrt{182{,}25 + 490{,}62} = \sqrt{672{,}87} \approx 25{,}94\ \Omega.$$

La valeur efficace cherchée est le rapport des modules multiplié par $U$ :

$$U_2 = U\cdot\frac{|\underline{Z_2}|}{|\underline{Z}_\text{ligne}+\underline{Z_2}|} = 240\cdot\frac{25}{25{,}94}\approx 231{,}3\ \text{V}.$$

2. Déphasage de u par rapport à u₂

Le déphasage de $\underline{U}$ par rapport à $\underline{U_2}$ est l'argument de $\underline{U}/\underline{U_2}$. D'après le diviseur :

$$\frac{\underline{U}}{\underline{U_2}} = \frac{\underline{Z}_\text{ligne}+\underline{Z_2}}{\underline{Z_2}}.$$

L'argument vaut donc :

$$\varphi_{u/u_2} = \arg(\underline{Z}_\text{ligne}+\underline{Z_2}) - \arg(\underline{Z_2}).$$

On calcule chacun :

$$\arg(\underline{Z}_\text{ligne}+\underline{Z_2}) = \arctan\!\frac{22{,}15}{13{,}5} \approx 58{,}65^\circ,\qquad \arg(\underline{Z_2}) = \frac{\pi}{3} = 60^\circ.$$

Donc :

$$\boxed{\,\varphi_{u/u_2} \approx 58{,}65^\circ - 60^\circ \approx -1{,}35^\circ\,}$$

La tension d'alimentation $u$ est en très léger retard sur la tension $u_2$ aux bornes du récepteur. Le déphasage est faible, ce qui est cohérent avec une ligne dont l'impédance est très petite devant celle du récepteur.
